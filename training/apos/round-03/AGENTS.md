# APOS Round 03 중앙제어 규칙
## 목적
15개 미션의 Identity·상태·계획·증빙 색인만 관리한다. 각 미션의 실제 코드/테스트/발표/학습자료는 개별 canonical repository/training/round-03-apos/에 기록한다.
## 실행 절차
READ 공식 미션/평가와 각 미션 main HEAD→PLAN 상태 변경→CHECK Mission-ID/Stable-Topic/Repo/Runtime SHA→기존 PR·Evidence readback→중앙 문서만 수정→별도 PR/QA→병합 후 동기화.
## Exit Gate
중앙 상태가 실제 미션 SHA/PR/Run의 검증된 범위와 일치해야 PASS. 미션 CORE·보너스·발표·범용 하네스 상태는 별도 Gate.
## 금지
코드와 슬라이드·증빙 복사, 과거 Round 파일을 새 결과처럼 사용, 임의 CLEAR, QA 없는 merge, 15개 미션 자동 일괄 시작 금지.

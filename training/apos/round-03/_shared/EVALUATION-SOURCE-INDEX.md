## 실제 적용 방법 — 새 문서 양산보다 실행

1. 공식 평가 질문 한 개를 읽고 실제 함수·코드 위치를 찾는다.
2. 정상·오류·경계 조건을 브라우저/CLI/API/DB 환경에서 직접 재현한다.
3. 본인이 30초·1분으로 **WHAT → WHY → HOW → VERIFY → LIMITATION** 설명한다.
4. 시험 결과·스크린샷·Commit SHA를 해당 미션 evidence 원본에 연결한다.
5. 학습 슬라이드는 평가 질문·정확한 코드·실제 증빙을 1:1로 나타낸다.
6. 문항이 미완료이면 NOT_VERIFIED, 실제 평가를 받지 않았다면 OFFICIAL_EVALUATION_PENDING이다.

중앙관리 저장소의 Round 03 미션 폴더는 상태/색인만 기록합니다. 실제 평가 훈련과 코드는 해당 미션 저장소의 training/round-03-apos/01-mission, 07-evaluation, 08-presentation에서 업무 진행 시 연결합니다.

# Agent Codyssey Round 04 Agent — 학습자 중심 AI 교육·학습 통합 실행계획 V1.0

**적용:** B1-1~B7-2 총 15개 전용 저장소의 `training/round-04-agent/`에 동등한 계획·교육 폴더를 반영. 기존 00~09 고정 목차 유지.

**학습 목표:** 개념·용어 → 코드 예측·추적 → PRIMM 실습 → 오류 해결 → 자기 설명 → 장기 기억 → AI 도움 없이 독립 구현·응용.

**학습 방법 16개:** M01~M05 용어/개념, M06~M12 코드 예측·추적·작성·오류, M13~M16 자기 설명·전이·간격 복습·AI 튜터.

**AI 튜터:** H1 질문→H2 개념 힌트→H3 절차 힌트→H4 예제 해설; 학습자 요청과 도움 수준 기록. 생성 코드/정답은 외부·실행 검증 대상.

**품질 게이트:** QG-01 요구–학습–평가 연결; 02 사전/사후; 03 AI 콘텐츠 정확성; 04 PRIMM; 05 오답·피드백; 06 독립 수행; 07 접근성/부담; 08 개인정보/실습 보안.

**슬라이드:** 발표 16장, 학습 45장, 기술 심화 15~25장, 복습 1~2장과 `06-learning-activities/`의 용어·개념도·코드 추적·실습·디버깅·문제은행·복습 자료.

**성과:** L1 코드 보며 설명, L2 도식만 보고 설명, L3 자료 없이 설명, L4 빈 환경 직접 재현, L5 새로운 문제에 응용. 미션 기능 PASS/슬라이드 제작 PASS/학습 숙달 MASTER 독립 판정.

**단계 연계:** 00 계획→01 공식 요구 연결→02 진단/자료 분석→03 학습·실습 설계→04 신규 코드(별도 승인)→05 시험→06 증빙→07 평가→08 자료 제작→09 인계.

**현재 반영 범위:** 승인된 계획/공통 표준/폴더 README 준비. 실제 학습자 진단 자료, 문제은행 문제, PPTX/PDF, 신규 코드 및 평가 결과는 `NOT_STARTED/NOT_VERIFIED`.

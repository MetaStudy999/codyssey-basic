# Beginner Training Standard

Round 01의 모든 미션은 입문자가 처음부터 끝까지 따라 재현할 수 있어야 합니다.

## 기본 설명 순서

`왜 → 무엇 → 용어/개념 → 실행 → 예상 결과 → 의미 → 오류 해결 → 완료 확인`

## 한 Step의 표준

1. 왜 이 작업을 하는가
2. 지금 무엇을 하는가
3. 필요한 용어
4. 필요한 개념
5. 주석이 포함된 명령 또는 코드
6. 예상 결과
7. 결과의 의미
8. 오류가 발생했을 때 확인할 것
9. 해결 방법
10. 완료 판정

## 코드·명령 주석

- 입문자가 해당 줄의 목적을 모를 가능성이 있으면 설명합니다.
- Shell 명령은 옵션의 의미도 필요한 경우 설명합니다.
- Python/JavaScript 등은 변수·함수·조건·반복·I/O·예외처리 등 핵심 흐름을 설명합니다.
- 닫는 괄호나 종료 태그처럼 의미 없는 줄마다 기계적으로 주석을 붙이지 않습니다.

## 용어

용어는 필요 시점에 제공합니다. `한국어 (English)`를 함께 표기하고 다음을 설명합니다.

- 한 줄 정의
- 쉬운 설명
- 왜 필요한가
- 현재 미션 어디에서 사용하는가
- 관련 용어

용어 전체를 미션 시작 전에 외우게 하여 진도를 막지 않습니다.

## 개념과 개념도

- 짧고 단순한 관계는 가로형을 사용할 수 있습니다.
- 가로로 길어지면 세로형을 우선합니다.
- 개념도 아래에는 반드시 쉬운 설명을 추가합니다.
- 그림이 미션 수행에 도움이 되지 않으면 억지로 만들지 않습니다.

## Round에 따른 독립성

- R01: 상세 설명·주석·정답 경로 제공
- R02: 요구사항 우선, 필요 시 Hint
- R03+: 점차 가이드 의존도를 줄이고 문제 해결·설계 판단을 늘림

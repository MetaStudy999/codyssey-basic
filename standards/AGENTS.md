# AGENTS.md — CODYSSEY Presentation Standards

이 디렉터리에서 발표자료 표준을 생성·수정·검토하는 Agent는 다음 파일을 우선 읽는다.

1. `PRESENTATION-CANONICAL-DECISIONS.md`
2. `ROUND-02-PRESENTATION-STANDARD.md`
3. `../templates/presentations/PRESENTATION-QUALITY-EVOLUTION.md`

## Mandatory Context Rule

최신 사용자 결정은 `PRESENTATION-CANONICAL-DECISIONS.md`가 우선한다.
오래된 Deck, 이전 채팅, AI 기억이 Canonical Decision과 충돌하면 사용하지 않는다.

## Non-regression Rules

다음으로 회귀하지 않는다.

- Study-first → Presentation-first
- Image-first → 일반 PPT-native 카드형 슬라이드
- Text-minimal → 한 장에 작은 글자 다량 배치
- More-slides-allowed → 임의 12~16장 축소
- Actual Code → AI-generated Code
- Actual Evidence → AI-generated Runtime
- Mission PASS → Human Mastery 자동 PASS

## Core Pair

```text
IMAGE-FIRST + TRUTH-FIRST
```

두 기준을 함께 만족해야 한다.

## Mission-local Context

각 Mission에 Presentation Pack이 있으면 다음을 추가로 읽는다.

- `GOLDEN-DECK-QUALITY.md`
- `IMAGE-STUDY-DECK-V3-ROADMAP.md`
- `TRUTH-REPLACEMENT-MAP.md`
- `EVIDENCE-MAP.md`

없는 파일을 임의로 사실처럼 가정하지 않는다.

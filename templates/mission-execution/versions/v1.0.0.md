## Execution Flow

```text
01 기준 확정
→ 02 요구사항·평가항목 매핑
→ 03 Minimum Passing Path
→ 04 핵심 기능 통합 구현
→ 05 통합 Runtime 검증
→ 06 UX·포트폴리오 고도화
→ 07 공식 Bonus / Optional
→ 08 Troubleshooting
→ 09 최종 회귀검증
→ 10 Evidence·문서화
→ 11 평가 설명 준비
→ 12 모의평가
→ 13 CLEAR
```

## Core Mapping

Requirement

## Evaluation Explanation

```text
WHAT
→ WHY
→ HOW
→ VERIFY

```

## CLEAR

```text
공식 요구사항
+ 실제 구현
+ 실제 Runtime
+ Verification PASS
+ 필요한 Evidence
+ Evaluation 설명 가능
+ Secret 노출 없음
```

## 60-minute Sprint

| 시간 | 작업 |
|---|---|
| 0~5분 | 기준·평가 |
| 5~10분 | Minimum Passing Path |
| 10~35분 | 통합 구현 |
| 35~45분 | Runtime |
| 45~50분 | FAIL 수정 / Bonus |
| 50~55분 | Evidence / Docs |
| 55~60분 | Evaluation Review |

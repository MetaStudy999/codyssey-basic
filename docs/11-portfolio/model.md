# Portfolio Model

기존 Portfolio의 `Project + Competency + Evidence` 원칙을 V3에 보존하고 Growth Stage와 연결한다.

## 기본 구조

```text
Problem
  ↓
Context / Constraints
  ↓
Decision
  ↓
Build
  ↓
Test / Runtime
  ↓
Troubleshooting
  ↓
Result
  ↓
Evidence
  ↓
Reflection / Next Step
```

## Portfolio Unit

각 Case Study는 다음을 포함한다.

- Project 또는 Mission
- 해결한 문제
- 본인 역할
- 핵심 기술과 Architecture
- 중요한 Trade-off
- Test / Runtime Evidence
- Bug / Incident / Troubleshooting
- Collaboration Evidence
- 정량·정성 결과
- 실패 또는 한계
- 다음 개선 방향

## Growth Stage별 Evidence

- CORE: Mission PASS, 구현, Test, Runtime, 설명
- EXPLORE: 비교, 활동 참여, 선택 근거
- ADVANCED: ADR, Benchmark, Experiment, Refactoring, Security/Performance 개선
- PRO: Real User, Production, OSS, 연구/기업/고객 결과
- EXPERT: 복잡한 판단, 조직/프로젝트 간 영향, Leadership, 새로운 방법

## Career 연결

Portfolio는 기술 목록을 늘리는 문서가 아니라 **직무 수행 가능성을 증명하는 Evidence Index**로 사용한다. Career Case Study와 Interview Story는 이 자료에서 파생한다.

# 11. Portfolio

Project + Competency + Evidence를 외부 사람이 빠르게 검증할 수 있도록 정리한다.

## 핵심 구성

- Project Case Study
- Competency Evidence
- Architecture Decision
- Test / Runtime / Troubleshooting Evidence
- Collaboration / Review Evidence
- External Activity / Research / Open Source Result
- Developer Growth Record

단순 기술 목록보다 **문제 → 판단 → 구현 → 검증 → 결과 → 회고**의 연결을 우선한다.

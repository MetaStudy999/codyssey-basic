# 00. Governance

과정 전체의 기준과 변경을 관리한다.

## 핵심 원칙

1. Mission PDF와 공식 Evaluation이 최우선이다.
2. 외부 참고자료는 공식 요구사항을 변경하지 않는다.
3. 필수/선택은 폴더 구조가 아니라 메타데이터다.
4. 실제 검증되지 않은 결과를 PASS로 표시하지 않는다.
5. v1.0 구조 변경은 실제 필요가 확인된 경우에만 수행한다.

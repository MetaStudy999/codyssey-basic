## 3. Mission-derived Scope

핵심 애플리케이션은 파일 기반 개인 가계부 CLI다.

- 거래 `add`: 날짜, 타입, 카테고리, 금액, 메모/태그를 입력하고 ID를 생성한다.
- `list`: 최신순 목록과 limit 등 옵션을 제공한다.
- `search`: 기간, 카테고리, 타입, 키워드, 태그 등 조건 검색을 지원한다.
- `summary`: 월별 총수입/총지출/잔액과 카테고리별 지출 TOP N을 출력한다.
- `budget set`: 월 예산을 저장하고 summary에서 사용률/초과 여부를 확인한다.
- `category add/list/remove`: 사용 중 카테고리 삭제 정책을 포함한다.
- `update`, `delete`: ID 기반 수정/삭제와 없는 ID 처리를 구현한다.
- `import/export`: 명시된 CSV 구조로 데이터를 가져오고 내보낸다.
- 프로그램 종료 후에도 거래/카테고리/예산 데이터가 유지되어야 한다.
- 대용량 파일을 한 번에 모두 메모리에 올리지 않고 generator 스트리밍을 적용한다.
- 공통 예외/로그/시간측정 등의 관심사를 decorator로 분리한다.
- type hints와 모듈 분리를 통해 책임과 데이터 계약을 명확히 한다.

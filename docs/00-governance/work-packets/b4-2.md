## 3. Mission-derived Scope

- React SPA로 단일 핵심 데이터 서비스 CRUD를 구현한다.
- `pages`, `components`, `hooks` 또는 `lib` 역할을 분리한다.
- 최소 5개 route, 목록/상세 route, Not Found, 주요 navigation을 제공한다.
- 최소 8개 재사용 컴포넌트를 두고 prop에 따라 동작/표시가 달라지게 한다.
- loading/error/empty UI 패턴을 재사용 가능한 컴포넌트로 통일한다.
- controlled form, 목록/상세 데이터, loading/error 상태를 React state로 관리한다.
- 데이터 조회/갱신 흐름 최소 1개를 custom hook으로 분리한다.
- CRUD는 Supabase 또는 Firebase의 원격 데이터를 기준으로 동작한다.
- 목록/상세/등록/수정/삭제 전체 흐름을 구현한다.
- 폼 필수값 검증, 에러 메시지, 제출 중 상태, 요청 실패 UI를 구현한다.
- 최소 3개 이상의 명확한 event → state → render 변화 지점을 확인한다.
- 배포 URL에서도 CRUD 전체가 동작하고 환경변수 누락이 없어야 한다.
- secret/API key는 `.env`와 배포 플랫폼 Environment Variables로 관리한다.

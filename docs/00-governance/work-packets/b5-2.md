## 3. Mission-derived Scope

- Python 가상환경과 `fastapi`, `uvicorn`, `sqlalchemy`, `jinja2`, `python-multipart` 중심으로 서버를 구성한다.
- `http://localhost:8000`에서 FastAPI가 정상 기동한다.
- `routers/`, `services/`, `repositories/`, `models/`, `templates/` 역할을 분리한다.
- 모든 주요 화면은 Jinja2 SSR `TemplateResponse`로 렌더링한다.
- 홈 `GET /`에 앱 설명과 최소 2개 주요 링크를 둔다.
- 단일 domain model 1개에 대해 목록/상세/등록/수정/삭제를 모두 구현한다.
- 등록/수정은 HTML Form + POST + FastAPI `Form()`으로 처리한다.
- 등록/수정/삭제 후 `RedirectResponse`와 303을 사용하여 PRG(Post-Redirect-Get)를 적용한다.
- 존재하지 않는 데이터 접근은 안내 화면 또는 안전한 이동으로 처리한다.
- router는 HTTP/화면 전환, service는 business logic, repository는 DB access를 담당한다.
- 저장은 in-memory list/dict가 아니라 SQLite + SQLAlchemy ORM을 기준으로 한다.
- DB Session은 FastAPI `Depends`로 주입한다.
- DB 파일을 직접 확인할 수 있는 방법을 제공한다.
- 로그인/권한/인증과 model relationship은 Source에서 다음 Mission 범위로 명시되어 있으면 Non-scope로 유지한다.

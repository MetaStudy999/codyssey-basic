## 3. Mission-derived Scope

- FastAPI 기반 웹 AI chatbot service를 완성한다.
- 사용자가 웹 UI에서 text question을 입력하고 AI response를 같은 서비스 흐름에서 확인한다.
- 회원가입/로그인과 인증 상태에 따른 접근 제어를 적용하고 chatbot 기능은 로그인 사용자만 사용한다.
- AI API call은 server-side에서 수행해 key를 browser에 노출하지 않는다.
- 최소 context strategy를 적용한다. 예: 최근 N개 대화 또는 같은 사용자/세션의 직전 Q/A.
- 사용자 질문과 AI 응답을 DB에 누적 저장한다.
- 최소 추적 필드로 사용자 식별, 생성 시각, 질문, 응답을 관리한다.
- 사용자 기준 로그 조회/추적이 가능해야 한다.
- AI API 실패/timeout에서 서비스 전체가 비정상 종료되지 않게 처리하고 원인을 logging한다.
- 평가 시점 외부 네트워크에서 접근 가능한 URL을 제공한다.
- GitHub Repository와 README/기술 문서에 문제 정의, target user, scenario, architecture, API spec, DB structure, deploy/run, team roles, secret management를 포함한다.
- DB 확인 가이드로 log API/admin view/SQL-script/evidence 중 Source가 허용하는 방법을 최소 1개 제공한다.
- branch/PR 기반 협업과 개인별 역할/작업 추적이 요구되면 실제 GitHub Evidence로 검증한다.

## 3. Mission-derived Scope

- VPC 1개와 Public Subnet 1개를 구성한다.
- Internet Gateway를 VPC에 연결하고 route table에 `0.0.0.0/0 -> IGW`를 둔다.
- Public Subnet instance가 outbound internet 통신 가능해야 한다.
- EC2 1대를 Public Subnet에 배치하고 SSH 접속 가능하게 한다.
- Nginx 등 웹 서버를 설치·실행하고 localhost에서 HTTP 200을 확인한다.
- Security Group은 필요한 port만 허용한다.
- HTTP 80은 외부 접근 가능, SSH 22는 개인/지정 IP 범위로 제한한다.
- `0.0.0.0/0` 전체 port 허용 같은 과도한 rule은 만들지 않는다.
- IAM user/role은 EC2/VPC/SG 실습 범위의 최소권한을 사용하고 `AdministratorAccess`를 사용하지 않는다.
- 외부 브라우저 또는 `/health` GET 중 Source가 허용하는 방식으로 public access를 검증한다.
- architecture diagram에 VPC/Subnet/IGW/EC2/SG와 external traffic flow를 표현한다.
- troubleshooting report 최소 1건을 증상 → 가설 → 검증 → 조치 → 결과 → 재발방지 형태로 남긴다.
- 실습 종료 후 EC2/EBS/EIP/IGW/VPC 등 과금 위험 리소스를 정리하고 checklist를 남긴다.

## 3. Mission-derived Scope

- Git이 초기화된 project root에서 CLI를 실행한다.
- `git status`로 변경 파일 상태를 수집한다.
- `git diff`로 변경 내용을 수집한다.
- 변경 사항이 없으면 적절한 메시지를 출력하고 AI API를 불필요하게 호출하지 않는다.
- AI API key는 환경변수로 관리하고 code에 hardcode하지 않는다.
- API 실패(네트워크/인증 등) 시 원인을 포함한 사용자용 오류 메시지를 출력한다.
- model, temperature, max_tokens 등 Source가 명시한 주요 parameter를 CLI option으로 변경할 수 있게 한다.
- commit command는 변경사항 기반 1줄 commit title을 생성하고 terminal에 출력한다.
- commit body를 제공할 경우 변경 파일/모듈 또는 핵심 변경 bullet 등 Source의 품질 기준을 지킨다.
- PR command는 1줄 title과 body draft를 생성한다.
- PR body는 `Why`, `What`, `How to Test` 등 Source가 요구한 section 구조와 최소 bullet을 갖춘다.
- AI 결과는 자동 적용보다 사용자가 검토·복사할 수 있는 draft로 제공한다.
- README에 설치, 환경변수, 실행 예시, 결과 예시, 주의사항을 포함한다.

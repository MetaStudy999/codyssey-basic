## 3. Mission-derived Scope

- 순수 HTML/CSS/JavaScript 기반 포트폴리오를 만든다.
- 시맨틱 태그 `header/nav/main/section/article/footer`를 사용한다.
- Hero, About, Skills, Projects, Contact, Footer 섹션을 구성한다.
- 이미지 `alt`, form label 연결 등 기본 접근성을 갖춘다.
- CSS 변수와 dark theme 변수를 정의하고 Flexbox/Grid를 사용한다.
- Mobile-first 반응형을 적용하며 Mission 기준 768px/1024px breakpoint를 확인한다.
- 모바일에서 navigation을 숨기고 hamburger menu를 제공한다.
- DOM 선택/수정과 `addEventListener`를 사용하고 inline `onclick`을 피한다.
- hamburger, smooth scroll, scroll-top, scroll에 따른 nav style, dark mode localStorage, scroll animation을 구현한다.
- Contact form은 required/email validation, inline error, success state를 제공한다.
- ES6+ 문법과 map/filter/forEach 등을 적절히 사용한다.
- GitHub API를 `fetch` + `async/await`로 호출하고 loading/success/error/empty 상태를 UI로 표현한다.
- 사용자 이벤트 → 상태 변화 → DOM update 흐름을 명확히 보여준다.
- GitHub Pages 등 공식 Source가 요구하는 방식으로 배포하고 외부 URL에서 검증한다.

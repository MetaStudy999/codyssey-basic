## 3. Mission-derived Scope

- 대소문자 비구분 CLI와 공백 문자열 인자/통일된 옵션 문법을 지원한다.
- Commit node는 `hash`, `message`, `author`, `timestamp`, `parents`를 포함한다.
- Commit graph는 DAG이며 hash로 빠르게 찾을 수 있고 hash는 세션 내 유일해야 한다.
- `keyword -> commit_hash 목록`, `author -> commit_hash 목록` 최소 2종 inverted index를 유지한다.
- 정렬 알고리즘을 직접 구현하고 `sorted()`와 `list.sort()`를 사용하지 않는다.
- 명령어: `INIT`, `BRANCH`, `SWITCH`, `COMMIT`, `LOG`, `LOG --sort-by=date|author`, `PATH`, `ANCESTORS`, `SEARCH`, `SEARCH --author`.
- `LOG` 기본 출력은 부모가 자식보다 먼저 나오도록 위상 정렬 성격을 만족한다.
- `PATH`는 parent 연결을 무방향 간선으로 본 최단 경로이며 동률 시 path 문자열 사전순 최소 규칙을 따른다.
- `ANCESTORS`는 모든 조상을 빠짐없이 출력한다.
- 검색은 전체 commit scan이 아니라 inverted index를 이용한다.
- Diff/Merge/정렬 성능 비교는 Source에서 Bonus로 확인되면 기본 완료 후 Backlog로 둔다.

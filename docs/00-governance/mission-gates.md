# Completion Gates

| Gate | 의미 | 완료 조건 |
|---|---|---|
| G1 SOURCE | 기준 확정 | Mission/Evaluation/운영자료 분석 |
| G2 BUILD | 구현 | 필수 요구사항 구현 |
| G3 TEST | 자동 검증 | 요구 테스트 통과 |
| G4 REVIEW | 리뷰 | BLOCKER 0, MAJOR 0 |
| G5 RUNTIME | 실제 실행 | 실제 OS/브라우저/클라우드 환경 확인 |
| G6 EVIDENCE | 증빙 | 요구 증빙 확보 |
| G7 LEARN | 학습 | 핵심 구조와 이유를 자기 말로 설명 |
| G8 MERGE | 완료 | PR을 main에 병합 |

`PASS`는 문서 존재가 아니라 구현 + 실제 검증 + 필수 Evidence를 의미한다.

# 09. Career

Mission과 Project의 Evidence를 직무 역량, Portfolio Case Study, Interview Story와 연결한다.

## 단계 연결

- CORE: GitHub/README/기본 Project Evidence
- EXPLORE: 직무·기업·산업 탐색
- ADVANCED: Case Study, Open Source, Technical Interview, Mock Interview
- PRO: 인턴/취업/기업 프로젝트에서 실제 역할 수행
- EXPERT: 고난도 기술 판단과 조직 수준 문제 해결

취업 준비는 마지막에 별도로 시작하지 않고 각 Mission의 Evidence를 지속적으로 축적한다.

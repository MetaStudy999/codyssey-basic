- ○ 2. **직접 만들기** — 요구사항에 맞는 코드와 설정을 직접 만듭니다.
- ○ 3. **테스트하기** — 만든 결과가 예상대로 동작하는지 확인합니다.
- ○ 4. **검토하기** — 요구사항 누락과 개선할 부분이 없는지 다시 확인합니다.
- ○ 5. **실제로 실행하기** — 실제 환경에서 직접 실행하여 결과를 확인합니다.
- ○ 6. **증빙 남기기** — 명령 결과, 로그, 화면, 링크 등 통과 근거를 남깁니다.

- ○ 8. **완료 반영하기** — 최종 결과와 상태를 정리하여 미션 완료로 반영합니다.

# Macro Growth vs Micro Learning

V3는 장기 성장 단계와 개별 Mission 학습 단계를 분리한다.

## Macro Growth Stage

`CORE → EXPLORE → ADVANCED → PRO → EXPERT`

이 축은 **전체 성장 위치**를 나타낸다.

- CORE: 기본을 이해하고 직접 완성
- EXPLORE: 넓게 경험하고 방향 탐색
- ADVANCED: 선택 영역 심화
- PRO: 실제 환경에서 전문 수행
- EXPERT: 고난도 판단과 Trade-off

## Micro Learning Level

기존 Learning 자산의 다음 구조를 보존한다.

`Level 0 Prerequisite → Level 1 Core → Level 2 Execution → Level 3 Principles → Level 4 Troubleshooting → Level 5 Evaluation → Review → Optional Deepening`

이 축은 **한 Mission 안에서 무엇을 학습·수행할 수 있는가**를 나타낸다.

## 관계

두 체계는 1:1 대응하지 않는다.

예를 들어 Level 5 Evaluation을 완료해도 자동으로 ADVANCED가 되는 것이 아니다. 반대로 ADVANCED 활동에서도 새로운 기술을 배우면 그 기술에 대해서는 Level 0~3 학습이 다시 필요할 수 있다.

권장 해석:

```text
CORE
├─ Level 0 Prerequisite
├─ Level 1 Core
├─ Level 2 Execution
├─ Level 3 Principles
├─ Level 4 Troubleshooting
├─ Level 5 Evaluation
└─ Review

EXPLORE
└─ 인접 기술/활동을 짧게 경험

ADVANCED
└─ Optional Deepening + Experiment + Architecture + Measurement

PRO
└─ Production / Real User / External Result

EXPERT
└─ Judgment / Trade-off / Create / Lead
```

위 매핑은 운영 가이드일 뿐 강제적인 1:1 Gate가 아니다.

## Advanced 용어 충돌 방지

기존 Vocabulary의 `90-advanced`는 **개별 Mission의 선택 심화 묶음**이다.

V3의 `ADVANCED`는 **장기 성장 단계**다.

따라서 문서에서는 다음 용어를 권장한다.

- 기존 `90-advanced`: `Optional Deepening` 또는 `Mission Advanced Unit`
- V3 `ADVANCED`: `Growth Stage: ADVANCED`

이 구분으로 같은 `Advanced` 단어가 다른 의미로 사용되는 혼선을 줄인다.

## PASS와 학습 수준

Mission `PASS`, Learning `MASTERED`, Growth Stage `ADVANCED`는 서로 다른 판정이다.

- PASS: 공식 Mission 요구와 Evidence 충족
- MASTERED: 해당 학습 범위를 충분히 설명·재현
- ADVANCED: 선택 영역을 깊게 개선·측정·비교하는 성장 단계

세 상태를 Dashboard에서 별도 축으로 표시한다.

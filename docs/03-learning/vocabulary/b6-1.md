## STOP RULE

다음 범위까지를 B6-1 필수 용어로 본다.

- 원본 Mission PDF가 직접 요구한 VPC/Subnet/Route Table/Internet Gateway/EC2/Security Group/IAM/Nginx/외부 접속/트러블슈팅/정리 관련 용어
- 위 요구사항을 구현하고 검증하기 위한 최소 네트워크·HTTP·SSH·CIDR·포트·로그·비용 용어
- 원본 보너스에 직접 등장한 HTTPS/Let’s Encrypt/Docker 관련 용어
- 정리 항목에 직접 등장한 NAT Gateway/ELB/ALB/RDS 관련 용어

다음은 현재 필수 범위에 포함하지 않는다.

- Kubernetes
- Terraform
- AWS CloudFormation
- Auto Scaling
- Multi-AZ 고가용성 설계
- 복잡한 로드밸런싱 아키텍처
- Private Subnet/NAT 중심 다계층 아키텍처
- AWS Organizations / Control Tower
- 고급 IAM 권한 경계 및 SCP
- 대규모 관측성 플랫폼
- CI/CD 파이프라인 전체 설계

이 항목들은 후속 고도화 단계에서 별도로 다룬다.

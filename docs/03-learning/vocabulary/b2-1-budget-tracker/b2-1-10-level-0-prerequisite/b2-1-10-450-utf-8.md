# UTF-8 (Unicode Transformation Format 8-bit)

**한 줄:** 한글을 포함한 문자를 바이트로 저장·교환하는 널리 쓰이는 문자 인코딩 방식이다.

**B2-1 위치:** import/export CSV는 UTF-8과 헤더 포함 규칙을 따른다.

**핵심 관계:** text → UTF-8 encoding → file exchange.

**초미니 확인:** 한글 메모가 CSV에서 깨지지 않게 하기 위해 원본이 고정한 인코딩은?

**V1 Gate:** UTF-8이 문자 인코딩 방식임을 말한다.

# 딕셔너리 (Dictionary)

**한 줄:** key와 value를 짝으로 저장하는 Python 자료구조다.

**B2-1 위치:** 거래 직렬화나 카테고리별 합계처럼 이름으로 값을 찾을 때 유용하다.

**핵심 관계:** key → value.

**초미니 확인:** `food`라는 키에 지출 합계를 연결하려면 어떤 구조가 편한가?

**V1 Gate:** dictionary를 key-value 구조로 말한다.

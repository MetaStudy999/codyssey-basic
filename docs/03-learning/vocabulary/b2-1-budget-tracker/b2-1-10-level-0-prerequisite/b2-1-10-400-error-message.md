# 오류 메시지 (Error Message)

**한 줄:** 무엇이 잘못됐는지 사용자에게 알려 주는 설명이다.

**B2-1 위치:** 원인과 해결 힌트를 보여 주고 Python stack trace는 노출하지 않아야 한다.

**핵심 관계:** exception/error → friendly message → recovery action.

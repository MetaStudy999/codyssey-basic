# 도움말 (Help)

**한 줄:** 명령과 옵션의 사용 방법을 사용자에게 보여 주는 안내다.

**B2-1 위치:** 모든 명령은 `--help`로 사용 방법이 출력되어야 한다.

**핵심 관계:** --help → usage/options → correct command use.

**초미니 확인:** 명령 사용법이 기억나지 않을 때 요구되는 옵션은?

**V1 Gate:** `--help`의 목적을 말한다.

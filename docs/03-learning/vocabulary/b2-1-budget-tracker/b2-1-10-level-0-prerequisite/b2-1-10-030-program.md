# 프로그램 (Program)

**한 줄:** 컴퓨터가 정해진 작업을 수행하도록 작성한 명령의 묶음이다.

**B2-1 위치:** 수입·지출을 저장하고 조회하는 명령들의 전체 묶음이 프로그램이다.

**핵심 관계:** code → execution → result.

**초미니 확인:** 소스 코드가 실행되어 사용자 작업을 처리하면 무엇이라 부를 수 있는가?

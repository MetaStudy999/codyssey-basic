# B2-1 Level 4 — Troubleshooting Unit Index

**목적:** B2-1의 입력·파일·ID·category·CSV·저장 안전성·종료 코드 문제를 증상에서 시작해 최소 수정과 재검증까지 연결한다.  
**Gate:** TROUBLESHOOTING — `Symptom → Observe → Layer → Hypothesis → Smallest Fix → Reverify → Recovery → Evidence`를 독립적으로 설명한다.  
**Visual Learning:** DEFERRED

## Source / Implementation 경계

- Mission/Evaluation 요구는 원본 Source를 우선한다.
- 구체적인 오류 메시지와 구현 위치는 현재 `MetaStudy999/codyssey-basic-b2-1-budget-tracker`의 `main` 기준이다.
- 현재 구현의 `BudgetError`, `@cli_guard`, JSONL, `os.replace()`, rollback import는 하나의 구현 선택이며 원본이 허용한 다른 설계를 배제하지 않는다.
- 기존 18/18 테스트 Evidence는 참고 근거이며 학습자의 직접 장애 진단을 대신하지 않는다.

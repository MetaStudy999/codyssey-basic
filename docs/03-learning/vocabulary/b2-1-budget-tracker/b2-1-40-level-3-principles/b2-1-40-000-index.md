## 확장성 연결

현재 구현의 generator는 조회 메모리 사용을 줄이지만, id 생성·update/delete·summary 등은 파일 전체 순회/재작성 비용이 남는다. 따라서 **Streaming = 전체 확장성 문제 해결**로 과장하지 않는다.

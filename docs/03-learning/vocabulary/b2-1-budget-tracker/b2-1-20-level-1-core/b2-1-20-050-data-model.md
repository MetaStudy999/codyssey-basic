# 데이터 모델 (Data Model)

**쉬운 뜻:** 데이터가 어떤 필드와 규칙을 가져야 하는지 정한 구조다.

**B2-1 위치:** Transaction 필드와 타입·검증 규칙을 정의한다.

**핵심 관계:** data model → valid object → storage/service contract.

**미니 확인:** amount가 양수여야 한다는 규칙도 모델과 연결되는가?

**Gate:** 데이터 모델을 구조+규칙으로 설명한다.

# 내보내기 (Export)

**쉬운 뜻:** 내부 거래 데이터를 외부에서 사용할 CSV 파일로 저장하는 기능이다.

**B2-1 위치:** `--month` 또는 날짜 범위 조건을 받아 `--out` 파일을 만든다.

**핵심 관계:** internal records → filter → CSV encode → output file.

**미니 확인:** export는 조건 없이 전체 데이터를 무조건 내보내도 되는가?

**Gate:** export의 조건과 CSV 스키마 관계를 설명한다.

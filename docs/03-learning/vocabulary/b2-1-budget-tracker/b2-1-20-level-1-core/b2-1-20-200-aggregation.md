# 집계 (Aggregation)

**쉬운 뜻:** 여러 레코드의 값을 합치거나 세어 하나의 통계 결과로 만드는 처리다.

**B2-1 위치:** 총수입·총지출·카테고리별 지출 합계를 계산한다.

**핵심 관계:** many transactions → aggregate → totals/rankings.

**미니 확인:** 거래 100건의 지출 합계를 하나의 숫자로 만드는 것은?

**Gate:** aggregation을 summary 계산의 핵심 메커니즘으로 설명한다.

# 타입 계약 (Type Contract)

**쉬운 뜻:** 함수가 어떤 형태의 입력을 받고 어떤 형태의 결과를 돌려주는지에 대한 약속이다.

**B2-1 위치:** 모델·저장소·서비스 사이 데이터 전달을 명확하게 이해하는 데 사용한다.

**핵심 관계:** caller expectation ↔ function signature ↔ returned type.

**미니 확인:** 타입 힌트가 명확하면 계층 사이 계약을 이해하기 쉬워지는가?

**Gate:** type contract를 계층 간 약속으로 설명한다.

# 데이터 무결성 (Data Integrity)

**쉬운 뜻:** 데이터가 규칙에 맞고 서로 모순되지 않은 상태를 유지하는 성질이다.

**B2-1 위치:** 유효한 거래, 존재하는 category, 안전한 import/update/delete가 무결성과 연결된다.

**핵심 관계:** validation + reference rules + safe writes → integrity.

**미니 확인:** 사용 중인 category를 아무 확인 없이 삭제하면 무결성이 깨질 수 있는가?

**Gate:** 데이터 무결성을 정확성+일관성으로 설명한다.

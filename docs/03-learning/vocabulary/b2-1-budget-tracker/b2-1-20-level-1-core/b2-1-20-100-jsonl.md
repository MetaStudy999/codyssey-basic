# JSON 라인 (JSON Lines, JSONL)

**쉬운 뜻:** 한 줄에 JSON 객체 하나씩 기록하는 파일 형식이다.

**B2-1 위치:** 현재 구현이 transactions/categories/budgets의 애플리케이션 저장에 선택했다.

**핵심 관계:** one record per line → sequential iteration → generator-friendly storage.

**미니 확인:** 현재 구현의 애플리케이션 저장 형식은 JSONL인가 CSV인가?

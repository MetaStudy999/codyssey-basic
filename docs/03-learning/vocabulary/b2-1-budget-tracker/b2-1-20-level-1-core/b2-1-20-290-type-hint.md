# 타입 힌트 (Type Hint)

**쉬운 뜻:** 변수·매개변수·반환값에 기대하는 데이터 타입을 코드에 표시하는 문법이다.

**B2-1 위치:** 함수와 데이터 구조의 입력/출력 계약을 더 명확히 설명하게 한다.

**핵심 관계:** type hint → readable contract → easier maintenance/review.

**미니 확인:** 타입 힌트는 Python 런타임 검증 그 자체와 완전히 같은가?

**Gate:** type hint의 문서화·가독성 이점을 설명한다.

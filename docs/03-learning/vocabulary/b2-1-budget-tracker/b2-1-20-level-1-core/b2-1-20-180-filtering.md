# 필터링 (Filtering)

**쉬운 뜻:** 조건에 맞는 데이터만 통과시키고 나머지를 제외하는 처리다.

**B2-1 위치:** 날짜 범위, category, type, q, tag가 필터 조건이 된다.

**핵심 관계:** record → predicate → keep or skip.

**미니 확인:** 여러 조건을 모두 적용하는 검색도 filtering인가?

**Gate:** filtering을 조건 판정 흐름으로 설명한다.

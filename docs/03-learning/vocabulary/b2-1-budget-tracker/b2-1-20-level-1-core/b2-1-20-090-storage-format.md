# 저장 포맷 (Storage Format)

**쉬운 뜻:** 데이터를 파일 안에 어떤 문법과 구조로 기록할지 정한 형식이다.

**B2-1 위치:** 원본은 JSONL 또는 CSV 중 하나를 애플리케이션 저장 형식으로 선택하게 한다.

**핵심 관계:** object ↔ format encoding ↔ file.

**미니 확인:** JSONL과 CSV는 둘 다 저장 포맷인가?

**Gate:** 저장 포맷이 데이터 표현 규칙임을 말한다.

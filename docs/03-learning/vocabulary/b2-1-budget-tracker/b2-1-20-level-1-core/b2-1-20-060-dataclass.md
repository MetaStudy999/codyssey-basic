**쉬운 뜻:** 데이터 필드 중심 클래스를 간결하게 정의하도록 돕는 Python 기능이다.

**B2-1 위치:** 현재 구현의 Transaction 모델에 사용한다.

**핵심 관계:** dataclass → declared fields → Transaction object.

**미니 확인:** 반복적인 초기화 코드를 줄이며 구조화된 거래 데이터를 만들 수 있는 Python 기능은?

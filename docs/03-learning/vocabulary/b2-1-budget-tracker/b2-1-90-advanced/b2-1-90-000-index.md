# B2-1 Advanced — Optional Bonus & Deepening Index

**목적:** 원본 B2-1 Mission의 선택 보너스를 필수 PASS와 분리해 수행하고, 추가 심화는 별도 범위로 관리한다.  
**Gate:** OPTIONAL-DEEPENING  
**Visual Learning:** DEFERRED

## Source Lock — 원본 Bonus 4개

원본 Mission PDF의 선택 보너스는 다음 4개다.

1. `backup` 실행 시 **타임스탬프가 포함된 백업 파일 생성**
2. 월급/월세처럼 **반복 내역을 등록하고 특정 월에 자동 생성**
3. 외부 라이브러리 없이 **문자열 정렬로 콘솔 출력 가독성 개선**
4. update/delete 시 **임시 파일에 쓰고 rename/교체하는 저장 원자성 강화**

배움 포인트는 각각 `복구 가능성`, `규칙 기반 데이터 생성 + 예외 처리`, `콘솔 UX + 포맷터 분리`, `파일 기반 트랜잭션/원자성 사고`다.

## Scope 구분

```text
SOURCE_LINKED_BONUS
→ 원본 Mission Bonus에 직접 연결

SUPPLEMENTAL_ADVANCED
→ Bonus를 이해하기 위해 추가한 심화

MIXED_OPTIONAL
→ Source-linked Bonus와 추가 심화를 통합 점검
```

현재 구현의 `storage.py`는 이미 `tempfile → flush → fsync → os.replace()` 방식의 재작성을 사용한다. 이는 Bonus 4와 직접 연결되는 **현재 구현 Evidence**다. 그러나 backup/반복 내역/표 정렬까지 완료되었다는 뜻은 아니며, Advanced 구조화 자체도 Bonus 수행 완료를 의미하지 않는다.

**목적:** B2-1의 실제 구현 저장소를 읽고, 명령을 직접 실행하고, 결과와 Evidence를 확인하는 V4 단계다.  
**Gate:** V4 — `명령/입력 → 상태 변화 → 검증 → Evidence`를 독립적으로 수행하고 설명할 수 있다.

## Source / Runtime 경계

- Mission 요구는 원본 `b2-1-mission.pdf`와 Mission Index의 Source Lock을 우선한다.
- 아래 명령과 구현 위치는 현재 `MetaStudy999/codyssey-basic-b2-1-budget-tracker`의 `main` 기준이다.
- 현재 구현 저장소에는 `evidence/test-results.txt`, `evidence/cli-transcript.txt`, `evidence/sample-export.csv`가 존재하며, 저장된 테스트 결과는 **18 tests / 18 passed / 18.176s**다.
- 기존 Evidence는 구현 상태를 이해하기 위한 참고 근거다. 학습자의 V4 Gate는 직접 실행·확인해야 한다.

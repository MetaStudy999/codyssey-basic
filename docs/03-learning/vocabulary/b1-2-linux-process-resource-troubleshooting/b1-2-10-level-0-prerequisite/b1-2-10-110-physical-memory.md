# 물리 메모리 (Physical Memory)

## 한 줄 설명
실제 RAM에서 프로세스가 사용하는 메모리 자원이다.

## B1-2에서의 위치
미션은 대상 프로세스의 물리 메모리 사용량 증가 패턴을 관측하도록 요구한다.

## 핵심 관계
`Process → Physical Memory → Monitoring`

## 초미니 확인
시간에 따른 메모리 증가를 관제 로그에서 비교한다.

# 쓰기 권한 (Write Permission)

## 한 줄 설명
파일이나 디렉터리에 데이터를 기록할 수 있는 권한이다.

## B1-2에서의 위치
로그 디렉터리는 존재뿐 아니라 쓰기 권한도 필요하다.

## 핵심 관계
`Permission → Log Write → Runtime`

## 초미니 확인
로그 디렉터리에 쓰기 권한이 없을 때의 문제를 말한다.

## V1 Gate
- [ ] 쓰기 권한의 의미를 안다.

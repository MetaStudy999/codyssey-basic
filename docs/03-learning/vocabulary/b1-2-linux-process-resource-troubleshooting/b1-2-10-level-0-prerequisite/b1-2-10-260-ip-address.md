# 인터넷 프로토콜 주소 (Internet Protocol Address, IP Address)

## 한 줄 설명
네트워크에서 인터페이스나 호스트를 식별하는 주소다.

## B1-2에서의 위치
`0.0.0.0`은 모든 인터페이스 바인딩 문맥에서 사용된다.

## 핵심 관계
`IP Address + Port → Endpoint`

## 초미니 확인
`0.0.0.0`과 특정 IP 바인딩을 구분한다.

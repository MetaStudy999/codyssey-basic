# 명령줄 인터페이스 (Command-Line Interface, CLI)

## 한 줄 설명
텍스트 명령으로 시스템과 프로그램을 제어하는 방식이다.

## B1-2에서의 위치
관제·재현·진단 작업 대부분을 CLI 명령으로 수행한다.

## 핵심 관계
`CLI → ps / top / kill / grep`

## 초미니 확인
프로세스 상태를 확인하는 CLI 명령 하나를 말한다.

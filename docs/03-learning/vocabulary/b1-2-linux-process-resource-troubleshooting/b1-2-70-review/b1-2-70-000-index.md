# B1-2 Review — Integrated Review Index

**목적:** Level 0~5에서 배운 B1-2 내용을 새로 설명받기보다 `회상 → 관계 복원 → 장애 진단 → Evidence 연결 → 자기 설명`으로 다시 꺼내 쓴다.  
**최종 Gate:** LEARNING READY  
**Visual Learning:** DEFERRED

> Source Boundary: 원본 Mission PDF가 authoritative Source다. 실제 Runtime Evidence는 현재 구현 저장소의 관측 결과를 참고하며, `b1-2-evaluation.md`는 official provenance가 확인되지 않은 `UNVERIFIED` provisional practice rubric으로만 사용한다.

## Review 흐름

```text
RECALL
→ RELATE
→ DIAGNOSE
→ EVIDENCE
→ EXPLAIN
→ RETRIEVE AGAIN
→ LEARNING READY
→ ADVANCED / NEXT BRIDGE
```

## 상태 구분

```text
REVIEW STRUCTURE READY
≠ LEARNING READY
≠ PERSONAL MASTERED
≠ RUNTIME VERIFIED
≠ MISSION PASS
```

학습 문서가 준비됐다는 사실은 학습자가 백지에서 재현하거나 실제 시스템을 다시 검증했다는 뜻이 아니다.

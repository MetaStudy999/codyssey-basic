# Five-minute Blank Reconstruction

## 복습 목표

5분 동안 아무 자료 없이 B1-2의 구조를 한 장에 복원한다.

## 5분 타이머 과제

### 0:00–1:00 — Mission Map

OOM / CPU / Deadlock 세 갈래와 Evidence → RCA → Workaround → Before/After를 그린다.

### 1:00–2:00 — 고정 조건

`15034`, non-root, 세 핵심 환경변수와 범위, `AGENT_*`, `secret.key`를 적는다.

### 2:00–3:00 — 세 장애 Evidence

각 장애마다 `증상 / 관찰 / 핵심 Evidence / 변경 변수 / After 결과` 5칸을 채운다.

### 3:00–4:00 — 원리와 Troubleshooting

Memory protection, per-process CPU, Process/Thread/Lock/Deadlock, 공통 장애 진단 알고리즘을 적는다.

### 4:00–5:00 — 평가 설명

`WHAT → WHY → HOW → PROOF → LIMIT → FOLLOW-UP`을 쓰고 세 리포트 구조를 복원한다.

## 채점 원칙

- 빠뜨린 항목은 해당 Level로 돌아간다.
- 표현이 달라도 관계가 정확하면 인정한다.
- Reference Runtime 숫자를 외웠어도 원리와 Evidence 연결이 없으면 부족하다.
- 없는 Evidence를 기억으로 만들어 쓴 경우 실패로 본다.

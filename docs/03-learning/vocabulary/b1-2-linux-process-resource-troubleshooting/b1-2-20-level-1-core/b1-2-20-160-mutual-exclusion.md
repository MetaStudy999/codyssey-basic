# 상호 배제 (Mutual Exclusion)

## 한 줄 설명

## B1-2에서의 위치
교착상태 4대 조건 중 하나다.

## 핵심 관계
`Exclusive Resource → Lock`

## 초미니 확인
공유 자원에 상호 배제가 필요한 이유를 말한다.

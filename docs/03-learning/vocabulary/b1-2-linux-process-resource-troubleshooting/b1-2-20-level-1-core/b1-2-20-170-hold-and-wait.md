# 점유 대기 (Hold and Wait)

## 한 줄 설명
이미 가진 자원을 놓지 않은 채 다른 자원을 기다리는 조건이다.

## B1-2에서의 위치
교착상태 4대 조건 중 하나다.

## 핵심 관계
`Hold Resource A + Wait Resource B`

## 초미니 확인
자원을 하나 가진 채 다른 자원을 기다리는 상황을 설명한다.

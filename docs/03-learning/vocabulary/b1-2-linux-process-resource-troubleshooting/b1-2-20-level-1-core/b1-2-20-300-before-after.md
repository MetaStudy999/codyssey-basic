# 전후 비교 (Before & After Comparison)

## 한 줄 설명
설정 변경 전과 후의 결과를 같은 기준으로 비교하는 검증 방식이다.

## B1-2에서의 위치
`MEMORY_LIMIT`, `CPU_MAX_OCCUPY`, `MULTI_THREAD_ENABLE` 변경 효과를 입증한다.

## 핵심 관계
`Baseline → Change → Re-run → Compare`

## 초미니 확인
환경 변수 하나만 바꾸고 같은 조건으로 재실행해야 하는 이유를 말한다.

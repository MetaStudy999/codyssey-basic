# 증거 자료 (Evidence)

## 한 줄 설명
주장을 객관적으로 뒷받침하는 로그·명령 출력·스크린샷 등의 자료다.

## B1-2에서의 위치
PID, 타임스탬프, 핵심 로그, 관제 수치를 각 리포트에 연결한다.

## 핵심 관계
`Claim → Evidence → Report`

## 초미니 확인
'느려졌다'는 느낌과 Evidence의 차이를 말한다.

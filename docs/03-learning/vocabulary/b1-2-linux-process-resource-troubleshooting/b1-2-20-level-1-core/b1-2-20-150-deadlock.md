# 교착상태 (Deadlock)

## 한 줄 설명
둘 이상의 실행 주체가 서로 가진 자원을 기다리며 영원히 진행하지 못하는 상태다.

## B1-2에서의 위치
PID는 남아 있지만 CPU/MEM 변화와 로그 출력이 멈춘 상태를 Evidence로 진단한다.

## 핵심 관계
`Circular Waiting → No Progress`

## 초미니 확인
PID 존재만으로 정상이라고 판단할 수 없는 이유를 말한다.

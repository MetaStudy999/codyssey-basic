# CPU 과점유 (High CPU Usage)

## 한 줄 설명
한 프로세스가 CPU 자원을 지나치게 많이 사용하는 상태다.

## B1-2에서의 위치
시스템 전체 부하가 아니라 대상 프로세스 과점유임을 입증해야 한다.

## 핵심 관계
`Per-process CPU → System Impact`

## 초미니 확인
과점유가 시스템 지연에 영향을 줄 수 있는 이유를 말한다.

## V2/V3 Gate
- [ ] 특정 프로세스 CPU와 시스템 영향을 연결한다.

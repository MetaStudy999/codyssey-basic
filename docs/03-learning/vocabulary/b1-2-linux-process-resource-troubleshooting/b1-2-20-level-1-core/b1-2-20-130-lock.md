# 락 (Lock)

## 한 줄 설명
동시에 접근하면 안 되는 자원을 한 실행 주체가 사용하도록 제한하는 동기화 장치다.

## B1-2에서의 위치
WAITING/BLOCKED 로그를 락 대기 관계로 해석한다.

## 핵심 관계
`Thread → Lock → Waiting`

## 초미니 확인
Lock이 왜 필요하면서도 Deadlock 위험과 연결되는지 말한다.

# 자원 경쟁 (Resource Contention)

## 한 줄 설명
여러 실행 주체가 같은 제한된 자원을 동시에 사용하려고 경쟁하는 상태다.

## B1-2에서의 위치
Deadlock이 발생할 수 있는 배경 조건으로 설명한다.

## 핵심 관계
`Threads + Shared Resource → Contention`

## 초미니 확인
자원 경쟁과 Deadlock을 같은 상태로 보지 않는 이유를 말한다.

## V2/V3 Gate
- [ ] 경쟁이 교착상태 위험으로 이어질 수 있음을 설명한다.

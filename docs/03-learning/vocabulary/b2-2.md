# B2-2 미션 용어 지도

**미션:** 친구 3~5명과 함께 프로그램 만드는 법 연습하기  
**분야:** Python과 Git 심화 (Python & Git Advanced)  
**학습시간:** 20시간  
**표기 원칙:** 한글 용어 (English Term, 약어)  
**상태:** 1차 용어 목록 작성 완료 — 설명은 후속 학습 단계에서 추가

> 기준: B2-2 원본 Mission PDF의 미션 소개, 최종 결과물, 과제 목표, 기능 요구 사항, 보너스 과제, 개발 환경, 제약 사항, 결과 예시를 우선 반영한다. 원본에서 직접 요구하거나 구현·협업·검증·평가에 필요한 용어를 중심으로 구성하며, 현재 단계에서는 용어 설명을 넣지 않는다.

- 브랜치 분리
- 파일 변경 이력
- README 및 문서 관리
- CLI 기반 Git 명령 수행

### DEEPEN

- 개인 버전 관리 → 팀 버전 관리
- 커밋 → 커밋을 가리키는 브랜치 포인터
- 저장소 → Organization / Collaborator 기반 팀 저장소
- 단순 push → Issue / PR / Review 기반 협업
- 단순 오류 해결 → 재현 가능한 Git 트러블슈팅 기록

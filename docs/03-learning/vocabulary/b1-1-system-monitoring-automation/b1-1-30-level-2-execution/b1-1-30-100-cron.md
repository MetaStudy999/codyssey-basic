# B1-1 — cron

## 한 줄 설명
`agent-admin`의 crontab에서 `monitor.sh`를 매분 자동 실행하고 등록 사실이 아니라 실제 로그 증가로 동작을 검증한다.

## 원본 핵심
```text
executor = agent-admin
schedule = every minute
```

현재 저장소 예시:
```text
* * * * * /home/agent-admin/agent-app/bin/monitor.sh >/dev/null 2>&1
```

## 핵심 관계
```text
crontab 등록 → cron daemon → monitor.sh 실행 → monitor.log 증가
```

대표 검증:
```bash
sudo -u agent-admin crontab -l
systemctl status cron --no-pager
before=$(wc -l < /var/log/agent-app/monitor.log)
sleep 70
after=$(wc -l < /var/log/agent-app/monitor.log)
printf 'before=%s after=%s\n' "$before" "$after"
```

## 초미니 확인
`crontab -l`에 줄이 보이면 자동 실행까지 PASS인가? → **아니다. 실제 로그 증가를 확인한다.**

## V4 Gate
- [ ] `agent-admin`의 crontab을 확인할 수 있다.
- [ ] `* * * * *`가 매분 실행임을 식별할 수 있다.
- [ ] cron 서비스와 실제 로그 증가를 확인할 수 있다.

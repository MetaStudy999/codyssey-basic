# B1-1 Level 2 — Execution Unit Index

**목적:** Level 2의 많은 명령·설정 용어를 무조건 한 파일씩 쪼개지 않고, 실제 수행 흐름상 함께 배워야 하는 **독립 실행 학습 단위**로 묶어 V4까지 연결한다.  
**Gate:** V4 — Locate / Apply  
**Source:** B1-1 원본 Mission/Evaluation + 기존 `b1-1-30-level-2-execution.md` + 현재 구현 저장소.

> Level 0/1은 `한 파일 = 한 용어`가 효과적이지만 Level 2는 `chmod`, `750`, `rwxr-x---`처럼 하나의 실행 행위 안에서 동시에 해석해야 하는 용어가 많다. 따라서 Level 2는 **한 파일 = 하나의 독립적으로 수행·검증 가능한 실행 단위**를 기본으로 한다.

## 시각 학습 상태

Visual Learning은 **DEFERRED**다. 텍스트 학습, 명령 이해, V4 검증을 먼저 진행한다.

## 전체 실행 흐름

```text
Preflight
→ Users/Groups
→ Permissions/ACL
→ SSH Safety
→ SSH Configuration
→ Firewall
→ Agent Environment/Key
→ Agent Runtime
→ monitor.sh
→ cron
→ logrotate
→ Evidence/V4
```

## 완료 기준

- [ ] 각 실행 단위에서 무엇을 바꾸는지와 왜 필요한지 말할 수 있다.
- [ ] 명령 실행 전 확인값과 실행 후 검증값을 구분한다.
- [ ] 원본 요구값과 현재 구현 저장소의 재현용 선택값을 구분한다.
- [ ] `문서 존재 = PASS`가 아님을 이해한다.
- [ ] 실제 Runtime Evidence가 없는 항목은 `NEEDS-RUNTIME`으로 남긴다.

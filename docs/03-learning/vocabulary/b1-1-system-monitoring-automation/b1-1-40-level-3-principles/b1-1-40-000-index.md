# B1-1 Level 3 — Principle Unit Index

**목적:** Level 2에서 수행한 설정·명령을 다시 외우는 것이 아니라, 왜 그렇게 동작하는지 구조와 원리로 설명한다.  
**Gate:** WHY / HOW — 관계와 메커니즘 설명  
**Source:** B1-1 원본 Mission/Evaluation + 기존 `b1-1-40-level-3-principles.md` + 현재 구현 저장소.

> Level 3는 **한 파일 = 하나의 독립 원리 학습 단위**를 기본으로 한다. 원리 파일은 명령 모음이 아니라 `구조 → 관계 → 왜 필요한가 → B1-1 사례 → 설명 확인` 흐름으로 작성한다.

## 시각 학습 상태

Visual Learning은 **DEFERRED**다. 텍스트 기반 원리 이해와 자기 설명을 먼저 진행한다.

## 완료 기준

- [ ] 명령을 말하지 않고도 각 구조가 왜 필요한지 설명할 수 있다.
- [ ] 설정값과 런타임 상태를 구분한다.
- [ ] 원본 요구와 현재 구현 선택을 구분한다.
- [ ] 장애가 생겼을 때 어느 층의 문제인지 먼저 분리할 수 있다.
- [ ] 전체 구조를 문서 없이 3~5분 설명할 수 있다.

## 전체 진단 흐름

```text
Symptom
→ Observe
→ Layer
→ Hypothesis
→ Smallest Fix
→ Reverify
→ Recovery
→ Evidence
```

## 금지 습관

```text
오류 → chmod -R 777
오류 → sudo로 전부 실행
오류 → restart 반복
오류 → 여러 설정을 한꺼번에 수정
오류 → 실패 흔적부터 삭제
```

## 완료 기준

- [ ] 오류 메시지와 발생 시점을 먼저 보존한다.
- [ ] 권한/설정/process/port/firewall/automation 층을 분리한다.
- [ ] 가장 작은 수정만 적용한다.
- [ ] 최초 실패 검증을 같은 방식으로 다시 실행한다.
- [ ] Before/After Evidence를 남긴다.

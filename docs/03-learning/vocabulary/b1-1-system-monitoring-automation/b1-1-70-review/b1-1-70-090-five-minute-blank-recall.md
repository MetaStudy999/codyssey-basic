# 5분 백지 복원

타이머 5분을 두고 문서를 보지 않는다.

## 1분 — 전체 흐름

```text
User/Group
Permission/ACL
SSH
Firewall
Environment/Key
Agent
monitor.sh
cron
logrotate
Evidence
```

## 1분 — 숫자

`20022`, `15034`, `20`, `10`, `80`, `10MB`, `10개`, 매분, `750`을 올바른 항목과 연결한다.

## 1분 — 권한

`common`, `core`, `monitor owner/group/mode`, `cron executor`를 복원한다.

## 1분 — 장애

- Process는 있는데 15034가 없다.
- 수동 monitor는 되는데 cron에서는 안 된다.

두 상황의 첫 확인 순서를 말한다.

## 1분 — 평가 설명

하나의 주제를 `WHAT → WHY → HOW → PROOF`로 말한다.

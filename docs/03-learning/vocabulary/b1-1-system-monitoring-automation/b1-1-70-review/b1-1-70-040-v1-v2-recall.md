# V1/V2 — 용어 인지와 한 줄 설명

## 구두 퀴즈

다음 용어를 보고 한 문장으로 설명한다.

```text
Linux
User / Group
Permission
ACL
PoLP
SSH / sshd
TCP / Port / LISTEN
Firewall
Process / PID
Environment Variable
Shell Script / Bash
Health Check
CPU / Memory / Disk
Log / Append
cron / crontab
Log Rotation
Evidence
```

## 통과 기준

- V1: 용어를 보고 알아본다.
- V2: 전문용어를 그대로 되풀이하지 않고 쉬운 말로 설명한다.
- 모르는 용어는 추측하지 않고 해당 Level 0/1 파일로 돌아간다.

## Gate

- [ ] 핵심 용어를 20~30초 안에 한 문장씩 설명할 수 있다.

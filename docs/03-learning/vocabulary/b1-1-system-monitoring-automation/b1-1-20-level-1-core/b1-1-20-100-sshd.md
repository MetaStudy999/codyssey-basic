# B1-1 — SSH 서버 데몬 (SSH Daemon, sshd)

## 한 줄 설명
서버에서 SSH 연결 요청을 기다리고 인증·세션 처리를 수행하는 서버측 서비스다.

## B1-1에서의 위치
`sshd_config`의 Port와 `PermitRootLogin` 설정, 실제 20022 LISTEN 검증과 연결된다.

## 핵심 관계
`SSH = 접속 프로토콜`, `sshd = 그 접속을 받는 서버 서비스`.

## 초미니 확인
설정 파일에 `Port 20022`를 썼다고 실제 LISTEN이 자동으로 증명되는 것은 아닌 이유를 말한다.

## Gate
- [ ] V2: SSH와 sshd의 차이를 설명한다.
- [ ] V3: 설정 → 서비스 → LISTEN → 접속 순서를 설명한다.

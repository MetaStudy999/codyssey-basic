# B1-1 — 포트 (Port)

## 한 줄 설명
하나의 IP 주소에서 어떤 네트워크 서비스로 연결할지 구분하는 번호다.

## B1-1에서의 위치
SSH는 `20022`, Agent는 `15034`를 사용한다.

## 핵심 관계
`IP = 서버 위치`, `Port = 그 서버 안의 서비스 입구`로 구분한다.

## 초미니 확인
같은 서버에서 SSH와 Agent가 서로 다른 포트를 사용하는 이유를 설명한다.

# B1-1 — 크론 (cron)

## 한 줄 설명
Linux에서 지정된 시간 규칙에 따라 작업을 자동 실행하는 스케줄링 서비스다.

## B1-1에서의 위치
`agent-admin`의 `monitor.sh`를 매분 자동 실행한다.

## 핵심 관계
`cron 서비스 → crontab 규칙 읽기 → 정해진 시간에 명령 실행`.

## 초미니 확인
수동 실행 성공만으로 cron 자동 실행 성공을 증명할 수 없는 이유를 설명한다.

# B1-1 — 전송 제어 프로토콜 (Transmission Control Protocol, TCP)

## 한 줄 설명
연결을 설정하고 데이터의 순서와 전달 상태를 관리하는 전송 계층 프로토콜이다.

## B1-1에서의 위치
방화벽 규칙에서 `20022/tcp`, `15034/tcp`로 필요한 서비스 포트를 구분한다.

## 핵심 관계
`Application Service → TCP Port → LISTEN / Connection`

## 초미니 확인
방화벽 규칙에 포트 번호뿐 아니라 `/tcp`가 붙는 이유를 설명한다.

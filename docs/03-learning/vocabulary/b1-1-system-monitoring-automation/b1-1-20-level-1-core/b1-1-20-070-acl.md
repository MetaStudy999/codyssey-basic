# B1-1 — 접근 제어 목록 (Access Control List, ACL)

## 한 줄 설명
기본 owner/group/others 권한보다 더 세밀하게 특정 사용자·그룹의 접근 권한을 지정하는 방식이다.

## B1-1에서의 위치
`upload_files`, `api_keys`, `/var/log/agent-app`의 역할별 접근 범위를 세밀하게 맞추는 데 사용한다.

## 핵심 관계
`chmod 기본 권한 → ACL 추가 규칙 → 실제 접근 결과`

## 초미니 확인
`getfacl`로 기본 권한과 추가 ACL 항목을 구분해 본다.

## Gate
- [ ] V2: chmod만으로 부족할 때 ACL이 왜 필요한지 설명한다.
- [ ] V3: ACL과 최소 권한의 관계를 말한다.

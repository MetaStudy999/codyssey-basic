# B1-1 — sudo (Superuser Do)

## 한 줄 설명
일반 사용자가 필요한 명령에 한해 관리자 권한을 잠시 사용하는 방식이다.

## B1-1에서의 위치
계정·권한·SSH·방화벽 같은 시스템 설정 변경에서 필요한 경우에만 사용한다.

## 핵심 관계
`Regular User → sudo 필요한 명령 → 관리자 권한 작업 → 다시 일반 사용자`

## 초미니 확인
모든 명령 앞에 `sudo`를 붙이지 않아야 하는 이유를 설명한다.

# B1-1 Advanced — Structured Deepening Index

**목적:** B1-1 필수 학습과 Review를 마친 뒤, 원본 Bonus와 운영 심화 기술을 서로 혼동하지 않고 선택적으로 확장한다.  
**상태:** OPTIONAL / 비필수  
**Visual Learning:** DEFERRED

> Advanced는 `MISSION PASS`를 대신하지 않는다. 원본 Bonus와 추가 심화 기술을 명확히 분리한다.

## 두 종류의 Advanced

```text
A. Source-linked Bonus
   ├─ report.sh 통계
   └─ 7일 압축 / Archive / 30일 삭제

B. Supplemental Advanced
   ├─ systemd
   ├─ journald / Syslog
   ├─ cgroups
   ├─ SELinux / AppArmor
   ├─ Metric / Time-Series
   └─ Prometheus / Grafana
```

## STOP RULE

다음 중 하나라도 충족하지 못하면 Advanced를 중단하고 B1-1 필수 학습으로 돌아간다.

- SSH `20022` / Root 원격 차단을 설명할 수 있다.
- User / Group / ACL을 실제로 검증할 수 있다.
- Agent READY와 TCP `15034 LISTEN`을 구분해 설명할 수 있다.
- `monitor.sh` 정상/실패 동작을 설명할 수 있다.
- cron에 의해 실제 로그가 증가하는 과정을 이해한다.
- `10MB / 10개` 로그 회전 정책을 설명할 수 있다.

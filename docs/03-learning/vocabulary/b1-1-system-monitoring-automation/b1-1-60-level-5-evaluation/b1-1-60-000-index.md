# B1-1 Level 5 — Evaluation Unit Index

**목적:** 구현 사실을 나열하는 데서 끝내지 않고 `WHAT → WHY → HOW → PROOF → LIMIT` 구조로 평가자에게 설명한다.  
**Gate:** V5 — Explain with Evidence  
**Source:** B1-1 원본 Mission/Evaluation + 기존 `b1-1-60-level-5-evaluation.md` + 현재 구현 저장소.

> Level 5는 **한 파일 = 하나의 독립 평가 설명 단위**를 기본으로 한다. 실제 Evidence가 없는 항목은 문서 설명만으로 PASS라고 주장하지 않는다.

## 시각 학습 상태

Visual Learning은 **DEFERRED**다. 현재는 말하기 구조, 근거 연결, 예상 꼬리질문 대응을 우선한다.

## 전체 답변 흐름

```text
WHAT
→ WHY
→ HOW
→ PROOF
→ LIMIT / ENVIRONMENT
→ Follow-up
```

## 완료 기준

- [ ] 미션 고정값을 정확히 말한다.
- [ ] 구현 이유와 구현 위치를 연결한다.
- [ ] 설정 파일과 Runtime Evidence를 구분한다.
- [ ] 환경별 구현 차이를 원본 요구로 과장하지 않는다.
- [ ] 1분 및 3~5분 설명이 가능하다.
- [ ] 실제 증거가 없는 항목은 한계를 명확히 말한다.

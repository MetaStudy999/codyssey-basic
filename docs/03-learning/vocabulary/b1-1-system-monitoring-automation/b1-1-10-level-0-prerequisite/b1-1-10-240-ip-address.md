# B1-1 — 인터넷 프로토콜 주소 (Internet Protocol Address, IP Address)

## 한 줄 설명
네트워크에서 장치나 인터페이스를 구분하는 주소다.

## B1-1에서의 위치
이 용어는 B1-1의 명령·권한·프로세스·네트워크·로그 설명을 읽기 위한 선수 개념이다. Level 0에서는 깊은 원리보다 **보고 알아보는 것(V1)**을 목표로 한다.

## 핵심 관계
IP Address + Port 조합으로 특정 서비스에 접근한다.

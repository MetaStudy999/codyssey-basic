**목적:** B1-1을 시작하기 전에 필요한 최소 선수 용어를 `한 파일 = 한 용어`로 확인한다.  
**Gate:** V1 — Seen / Recognition  
**Source:** 기존 B1-1 Level 0 선수지식 문서. 원본 Mission/Evaluation보다 우선하지 않는다.

> Level 0에서는 설정을 바꾸거나 깊은 내부 원리를 공부하지 않는다. 용어를 보고 알아보고, Level 1·2 문서를 읽을 수 있을 정도의 최소 관계만 확인한다.

만화·도식은 현재 **DEFERRED**다. 각 용어의 만화 제작 형식과 QA 기준은 [Visual Learning Backlog](../../../visual-learning-backlog.md)에 보존하며, 비시각 학습 자료 진행을 막지 않는다.

## 관계 묶음

```text
Terminal → Shell/Bash → Command → Linux
File → Directory → File System → Absolute Path
User → UID / Group → GID → r/w/x
Program → Process → PID
Network → IP Address + TCP Port
Environment Variable → Shell Script → Log
```

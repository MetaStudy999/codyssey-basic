# B1-1 — 절대 경로 (Absolute Path)

## 한 줄 설명
루트(`/`)부터 시작해 대상 위치를 완전히 나타내는 경로다.

## B1-1에서의 위치
이 용어는 B1-1의 명령·권한·프로세스·네트워크·로그 설명을 읽기 위한 선수 개념이다. Level 0에서는 깊은 원리보다 **보고 알아보는 것(V1)**을 목표로 한다.

## 핵심 관계
B1-1의 `/var/log/agent-app` 같은 경로를 정확히 지정할 때 사용한다.

## 초미니 확인
이 용어를 보았을 때 “무엇을 가리키는 말인지” 한 문장으로 말해 본다. 설정을 변경하지 않는다.

# V3 Vocabulary Bridge Index

V3 Learning은 기존 `docs/04-learning/vocabulary`의 대규모 학습 자산을 즉시 이동하지 않는다. 먼저 **V3 진입점에서 기존 자산으로 안정적으로 연결**하고, 링크/자동화/학습 흐름 검증 후 실제 경로를 단계적으로 정리한다.

## 원칙

- Macro Growth: `CORE → EXPLORE → ADVANCED → PRO → EXPERT`
- Micro Learning: `Level 0~5 → Review → Optional Deepening`
- 기존 `90-advanced`는 Micro Optional Deepening이며 V3 Macro `ADVANCED`와 같은 상태가 아니다.
- 학습 자료가 준비되었다고 Runtime/PASS가 자동 충족되는 것은 아니다.

## 다음 Migration 방식

Vocabulary는 대량 Rename/Move를 한 번에 수행하지 않는다.

```text
V3 Bridge Index
   ↓
기존 Link Validation
   ↓
Mission별 Source Lock
   ↓
새 경로가 실제로 필요할 때만 이동
   ↓
Redirect/Compatibility 확인
   ↓
Old Path 제거
```

현재 단계에서는 기존 Vocabulary Path를 **KEEP**한다.

# Learning & Research Resources

기존 `docs/08-resources`의 역할을 V3 Learning 안으로 흡수한다. 외부 자료는 공식 Mission 요구사항을 대체하지 않고 **이해·검증·확장**에 사용한다.

## Resource Categories

1. Official Documentation / Standards / RFC
2. Books / Textbooks
3. Foundational / Landmark / Recent Papers
4. Digital Libraries / Academic Search
5. MOOC / University Courses
6. Conference Talks / Technical Videos
7. Professional Organizations / Communities
8. Engineering Blogs / Postmortems
9. Datasets / Benchmarks / Leaderboards
10. Technology / Research News

## Priority

- `REQUIRED`: 현재 Mission 수행에 직접 필요한 공식 Source/문서
- `RECOMMENDED`: 개념·구현·검증을 강화하는 자료
- `OPTIONAL`: EXPLORE/ADVANCED 단계의 확장 자료

Growth Stage와 Priority를 혼동하지 않는다. 예를 들어 EXPLORE 단계의 활동이라도 특정 목표에 매우 중요하면 RECOMMENDED일 수 있다.

## Resource Quality

가능하면 다음 순서를 우선한다.

Official Docs / Standard / RFC → Primary Research → Reputable Technical Organization → High-quality Engineering Source → Secondary Explanation

## Registry

기계 판독용 Resource Registry는 기존 `config/resources.yaml`을 우선 보존하고, V3 Schema 변경은 링크와 자동화 영향도를 확인한 뒤 별도 수행한다.

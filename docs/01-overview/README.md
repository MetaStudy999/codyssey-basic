# 01. Overview

## 목적

기초과정 전체 구조와 학습 목표를 한눈에 이해한다.

## 과정 구조

Linux/OS → Python/Git → 자료구조/알고리즘 → Web/Front-end → Database/Back-end → Cloud/AI API → Term Project

## 수행 전략

- 공식 요구사항 기준으로 B1-1부터 B7-2까지 순차 수행한다.
- 하나를 완료·병합한 뒤 다음으로 이동한다.
- FAST TRACK으로 결과물을 먼저 완성한 뒤 LEARNING TRACK으로 깊이를 확보한다.
- 선택 Mission도 현재 통합 수행 범위에서는 모두 수행한다.

## 최종 역량

코드를 작성하는 것에서 끝나지 않고 실행, 장애 분석, 테스트, 배포, 설명, 협업, 증빙까지 할 수 있는 상태를 목표로 한다.

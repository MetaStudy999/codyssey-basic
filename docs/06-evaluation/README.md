# 06. Evaluation

## Traceability
Official Source → Requirement → Implementation → Test → Review → Runtime → Evidence → PASS.

## 평가 원칙
- 일반적인 Best Practice를 공식 요구사항처럼 추가하지 않는다.
- 실제 실행이 필요한 항목은 문서만으로 PASS하지 않는다.
- 평가문항, 코드, 테스트, 증빙이 서로 모순되지 않아야 한다.
- 개선 아이디어는 현재 미션 통과를 지연시키지 않으면 적용하고, 그렇지 않으면 Advanced Backlog로 이동한다.

## 대표 저장소의 역할
세부 Requirement ID는 각 미션 Repository에서 관리하고, 대표 저장소는 미션 단위의 완료/증빙 상태만 요약한다.

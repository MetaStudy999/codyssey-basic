# 10. Professional Growth

기초 미션을 수행하는 순간부터 전문가의 방식으로 성장하기 위한 확장 체계다. 공식 미션 요구사항이 아니며 기본 미션 완료를 지연시키지 않는다.

## 성장 축

### 1. Foundations
수학, 이산수학, 확률·통계, 선형대수, 최적화, 컴퓨터구조, 운영체제, 네트워크, 데이터베이스.

### 2. Competency
Skill Matrix, Gap Analysis, 분야별 숙련도.

### 3. Product & UX
Problem Discovery, User Research, Requirements, Accessibility, Product Metrics.

### 4. Standards Reading
RFC, W3C/WHATWG, 공식 Language/Framework Reference를 읽는 훈련.

### 5. Source Code Reading
유명 Open Source의 구조, Issue, PR, Design Discussion을 읽는다.

### 6. Open Source Contribution
USE → READ → ISSUE → SMALL FIX → PR → REVIEW → 지속 기여.

### 7. System Design
규모, 제약조건, Architecture, Trade-off, Failure, 개선을 분석한다.

### 8. Incident Analysis
실제 Postmortem을 읽고 Root Cause와 재발방지 관점으로 분석한다.

### 9. Security
Secure Development, Threat Modeling, OWASP, Privacy, Authorization.

### 10. Data & Evaluation
Metric, Benchmark, Experiment Design, Regression Test, AI Evaluation.

### 11. Production Engineering
Reliability, Observability, Logging, Metrics, Tracing, SRE, Capacity, Performance, FinOps.

### 12. Research
Paper Reading → Literature Review → Reproduce → Modify → Evaluate.

### 13. Governance & Ethics
Privacy, Data Governance, Responsible AI, Open Source License, Intellectual Property.

### 14. Knowledge System
Collect → Filter → Understand → Summarize → Connect → Practice → Explain → Review → Reuse.

### 15. Technical Communication
Write → Draw → Speak → Teach. README, 기술문서, Diagram, 발표, 교육으로 확장한다.

### 16. Professional Output
GitHub, 기술블로그, Open Source, Certification, Conference Talk, Paper, Product/Startup.

### 17. Community & Mentoring
전문학회, 개발자 커뮤니티, 멘토링, 네트워킹.

### 18. Expert Radar
`ADOPT / TRIAL / ASSESS / HOLD`로 기술 유행을 선별한다.

### 19. Growth Review
월간·분기·연간 리뷰로 실제 결과와 다음 Gap을 확인한다.

## Mastery Ladder

1. COMPLETE — 공식 미션 완료
2. UNDERSTAND — 원리와 코드 설명
3. REBUILD — 핵심 부분 재구현
4. EXTEND — 기능 고도화
5. MEASURE — 성능·품질 측정
6. PRODUCTIONIZE — 보안·운영·관측성
7. COMPARE — 논문·오픈소스·대안 비교
8. CONTRIBUTE — Open Source/Community 기여
9. CREATE — 독창적 기술·연구·제품

## 핵심 성장 루프
**Learn → Build → Break → Measure → Explain → Contribute → Challenge → Create**

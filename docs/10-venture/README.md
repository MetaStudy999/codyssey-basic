# 10. Venture

기술을 문제·사용자·제품·시장 가치로 연결하는 창업/사업화 경로를 관리한다.

## 기본 흐름

Problem Discovery → User Interview → Prototype → MVP → Validation → PoC → Business

## 단계 연결

- EXPLORE: 문제/시장 탐색과 사용자 인터뷰
- ADVANCED: Prototype, MVP, Customer Validation, 창업 공모전
- PRO: PoC, 실사용자, 유료 고객, 사업화
- EXPERT: 제품·기술·시장·조직 Trade-off 판단

아이디어만 있는 상태에서는 세부 폴더를 만들지 않고 Problem Bank/Registry에 기록한다.

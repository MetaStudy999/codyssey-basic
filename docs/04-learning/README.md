# 04. Learning

## FAST TRACK
Mission 분석 → 최소 충분 설계 → 구현 → 테스트 → 리뷰 → 실제 실행 → Evidence → PASS.

## LEARNING TRACK
완성 결과물 → 개념 이해 → 구조 이해 → 명령/코드 읽기 → 직접 실행 → 일부 수정 → 오류 해결 → 자기 설명 → 복습.

  ↓

  ↓

  ↓

  ↓

  ↓

  ↓

  ↓

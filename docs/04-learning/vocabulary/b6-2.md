# B6-2 미션 용어 지도

**미션:** 내가 고친 코드 설명을 AI가 대신 써주는 도우미 만들기  
**분야:** 클라우드와 AI API (Cloud & AI API)  
**학습시간:** 40시간  
**표기 원칙:** 한글 용어 (English Term, 약어)  
**상태:** 1차 용어 목록 작성 완료 — 설명은 후속 학습 단계에서 추가

> 기준: B6-2 원본 Mission PDF의 미션 소개, 최종 결과물, 과제 목표, 기능 요구 사항, 보너스 과제, 개발 환경, 제약 사항, 결과 예시를 우선 반영한다. 원본에서 직접 요구하거나 Git 변경 사항 수집, AI API 연동, 프롬프트 설계, 커밋/PR 초안 생성, 형식 검증, 민감정보 보호, 비용/요청 제한의 구현·검증·평가에 필요한 용어를 중심으로 구성하며, 현재 단계에서는 용어 설명을 넣지 않는다.

## STOP RULE 적용

B6-2의 1차 용어 범위는 원본 Mission PDF가 요구하는 **Git 변경 사항 수집 → AI API 호출 → Commit/PR 초안 생성 → 출력 검증 → Safe Mode → 문서화** 흐름까지만 필수 범위로 잡는다.

다음 항목은 원본 미션의 필수 구현 범위가 아니므로 현재 목록에서 확장하지 않는다.

- `git push` 자동 실행
- GitHub PR 생성 API 자동 호출
- 원격 저장소 자동 반영
- 복수 AI Agent 협업
- RAG 기반 코드베이스 분석
- Vector Database
- Fine-Tuning
- CI/CD 자동화

이러한 항목은 이후 고도화 단계에서 별도 학습 대상으로 다룬다.

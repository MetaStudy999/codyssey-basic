# B4-2 미션 용어 지도

**미션:** 버튼 누르면 화면이 스르륵 바뀌는 요즘 웹사이트 만들기  
**분야:** 웹 기초와 프론트엔드 (Web Basics & Frontend)  
**학습시간:** 80시간  
**표기 원칙:** 한글 용어 (English Term, 약어)  
**상태:** 1차 용어 목록 작성 완료 — 설명은 후속 학습 단계에서 추가

> 기준: B4-2 원본 Mission PDF의 미션 소개, 최종 결과물, 과제 목표, 기능 요구 사항, 보너스 과제, 개발 환경, 제약 사항, 결과 예시를 우선 반영한다. 원본에서 직접 요구하거나 React 구현·검증·평가에 직접 필요한 최소 용어를 중심으로 구성하며, 현재 단계에서는 용어 설명을 넣지 않는다.

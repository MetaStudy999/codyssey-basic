# B5-2 미션 용어 지도

**미션:** 글을 쓰고·보고·고치고·지울 수 있는 게시판형 웹 서비스 만들기  
**분야:** 데이터베이스와 백엔드 (Database & Backend)  
**학습시간:** 60시간  
**표기 원칙:** 한글 용어 (English Term, 약어)  
**상태:** 1차 용어 목록 작성 완료 — 설명은 후속 학습 단계에서 추가

> 기준: B5-2 원본 Mission PDF의 미션 소개, 최종 결과물, 과제 목표, 기능 요구 사항, 보너스 과제, 개발 환경, 제약 사항, 결과 예시를 우선 반영한다. 원본에서 직접 요구하거나 FastAPI 웹 애플리케이션 구현·검증·평가에 필요한 용어를 중심으로 구성하며, 현재 단계에서는 용어 설명을 넣지 않는다.

## STOP RULE

B5-2의 1차 용어 목록은 다음 기준으로 제한한다.

포함:

- 원본 Mission PDF에 직접 등장하는 용어
- FastAPI + Jinja2 + SQLite + SQLAlchemy 단일 모델 CRUD 구현에 직접 필요한 용어
- Router / Service / Repository / Model / Template 구조를 이해하는 데 필요한 용어
- Form / PRG / Redirect / Session / Depends를 검증하고 설명하기 위한 용어
- 원본 보너스 과제와 다음 미션 연결에 직접 필요한 용어

제외 또는 Advanced/다음 미션으로 분리:

- 로그인 / 인증 / 인가 구현
- 사용자 권한 모델
- 다중 모델 연관관계
- 복잡한 REST API 설계 확장
- Docker / Kubernetes
- 메시지 큐 / 캐시 / 분산 시스템
- 복잡한 SQLAlchemy 내부 구현
- 외부 라이브러리 추가

이 문서는 **B5-2를 수행하고, 오류를 검증하고, 평가에서 자신의 코드 구조를 설명하는 데 필요한 최소 충분 용어 지도**를 목표로 한다.

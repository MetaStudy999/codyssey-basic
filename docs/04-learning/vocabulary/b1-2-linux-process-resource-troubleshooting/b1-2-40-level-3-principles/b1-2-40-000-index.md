# B1-2 Level 3 — Principle Unit Index

**목적:** Level 2에서 관찰한 OOM / CPU / Deadlock 현상을 `왜 발생하는가`, `어떤 구조로 연결되는가`, `어떤 Evidence가 어떤 결론을 지지하는가`의 WHY/HOW 수준으로 설명한다.  
**Gate:** WHY / HOW  
**Visual Learning:** DEFERRED

> 원칙: Mission 요구, 실제 Runtime 관측, 학습용 원리 설명을 서로 구분한다. 실제 Evidence가 말하지 않는 내부 구현을 추측해 단정하지 않는다.

## 원리 지도

```text
Memory Growth / Release
→ Memory Limit / Protection

CPU Utilization
→ Per-process Load / Latency

Process
→ Thread
→ Lock / Resource Contention
→ Deadlock Four Conditions
→ Alive-but-Stalled

Signal / Protection Termination

Evidence
→ Causality
→ RCA
→ Reproducibility / Before & After
```

## Reference Runtime 경계

현재 구현 저장소의 실제 Runtime은 OOM, CPU, Deadlock 각각의 관측 근거를 제공한다. 하지만 실제 바이너리를 디컴파일하지 않았으므로 내부 코드 라인이나 숨은 구현을 원인으로 단정하지 않는다.

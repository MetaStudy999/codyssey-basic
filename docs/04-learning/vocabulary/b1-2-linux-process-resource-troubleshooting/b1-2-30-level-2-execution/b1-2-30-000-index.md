# B1-2 Level 2 — Execution Unit Index

**목적:** OOM / CPU Spike / Deadlock을 실제 실행에서 `재현 → 관찰 → Evidence → 단일 변수 변경 → 재실행 → Before & After`로 검증한다.  
**Gate:** V4 — Locate / Apply  
**Visual Learning:** DEFERRED

> Source Lock: B1-2 Mission PDF가 최우선이다. 구현 저장소의 `MISSION-WORK-PACKET.md`는 `b1-2-mission.md`의 사전조건 표 변환 충돌과 `b1-2-evaluation.md`의 공식 출처 미확인을 기록하고 있으므로, 충돌 시 PDF가 우선한다.

## 실행 원칙

```text
Source / Safety
→ Runtime Environment
→ Observability Baseline
→ OOM Before → OOM After
→ CPU Before → CPU After
→ Deadlock Before → Deadlock After
→ Evidence Curation
→ Issue Report Validation
→ V4 Gate
```

- Mission 예시 출력은 실제 Evidence가 아니다.
- 제공 바이너리는 non-root로 실행한다.
- 디컴파일/리버스 엔지니어링을 하지 않는다.
- 장애가 보이면 재부팅/강제종료보다 먼저 PID·자원·로그를 보존한다.
- Before/After에서는 해당 장애의 핵심 환경 변수 **하나만** 바꾸는 것을 기본으로 한다.

## Reference Runtime

현재 구현 저장소에는 실제 Linux 실행으로 확보된 OOM/CPU/Deadlock Evidence와 3개 보고서가 존재한다. 이 값은 **참고 가능한 실제 관측 결과**이지, 학습자가 그대로 복사할 정답값이 아니다.

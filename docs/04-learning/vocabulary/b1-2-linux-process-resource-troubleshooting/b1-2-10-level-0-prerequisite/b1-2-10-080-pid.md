# 프로세스 식별자 (Process Identifier, PID)

## 한 줄 설명
각 프로세스를 구분하는 번호다.

## B1-2에서의 위치
Deadlock에서 프로세스가 살아 있다는 증거로 PID 존재를 확인한다.

## 핵심 관계
`Process → PID → Evidence`

## 초미니 확인
PID 존재가 정상 동작과 같은 뜻이 아닌 이유를 말한다.

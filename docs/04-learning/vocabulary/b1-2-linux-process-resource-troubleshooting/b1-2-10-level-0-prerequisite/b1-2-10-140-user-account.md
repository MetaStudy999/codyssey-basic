# 사용자 계정 (User Account)

## 한 줄 설명
시스템에서 작업 주체를 구분하는 계정이다.

## B1-2에서의 위치
제공 앱은 root가 아닌 일반 사용자로 실행해야 한다.

## 핵심 관계
`User → Process Owner`

## 초미니 확인
현재 실행 사용자를 `whoami`로 확인한다.

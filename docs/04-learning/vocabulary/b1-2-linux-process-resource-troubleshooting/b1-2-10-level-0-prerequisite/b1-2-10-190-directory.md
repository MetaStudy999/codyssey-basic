# 디렉터리 (Directory)

## 한 줄 설명
파일과 하위 경로를 묶어 관리하는 공간이다.

## B1-2에서의 위치
`api_keys`, `upload_files`, 로그 디렉터리 존재가 부트 조건과 연결된다.

## 핵심 관계
`Directory → Path → File`

## 초미니 확인

# B1-2 Level 5 — Evaluation Unit Index

**목적:** OOM / CPU / Deadlock을 `WHAT → WHY → HOW → PROOF → LIMIT / ENVIRONMENT → FOLLOW-UP` 구조로 설명하고 실제 Evidence와 연결한다.  
**Gate:** V5 — Explain  
**Visual Learning:** DEFERRED

> Source Boundary: B1-2 원본 Mission PDF가 authoritative Source다. 구현 저장소의 `b1-2-evaluation.md`는 현재 official provenance가 확인되지 않은 `UNVERIFIED` provisional rubric이므로, 아래 평가 연습의 보조 체크리스트로만 사용한다.

## 평가 답변 프레임

```text
WHAT
→ 무엇을 관찰했는가?
WHY
→ 왜 그것이 문제인가?
HOW
→ 어떻게 재현·관찰·조치했는가?
PROOF
→ 어떤 PID / timestamp / log / Before&After가 근거인가?
LIMIT / ENVIRONMENT
→ 어떤 환경·build·측정 한계가 있는가?
FOLLOW-UP
→ 꼬리질문에 어떻게 확장해 답할 것인가?
```

## 평가 상태 경계

```text
EVALUATION READY
≠ PERSONAL MASTERED
≠ RUNTIME VERIFIED
≠ MISSION PASS
```

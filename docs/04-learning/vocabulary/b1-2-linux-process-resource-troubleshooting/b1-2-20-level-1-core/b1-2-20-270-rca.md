# 근본 원인 분석 (Root Cause Analysis, RCA)

## 한 줄 설명
관찰된 현상 뒤의 기술적 원인을 Evidence로 설명하는 분석 과정이다.

## B1-2에서의 위치
세 GitHub Issue 모두 Evidence를 바탕으로 Root Cause를 작성해야 한다.

## 핵심 관계
`Observation + Evidence → Cause`

## 초미니 확인
증상과 원인을 같은 문장으로 쓰지 않는 이유를 말한다.

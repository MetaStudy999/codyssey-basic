# B1-1 Review — Integrated Review Index

**목적:** Level 0~5의 학습을 `인지 → 의미 → 관계 → 적용 → 원리 → 장애 진단 → 평가 설명`으로 한 번에 통합 점검한다.  
**최종 Gate:** LEARNING READY  
**Source:** B1-1 원본 Mission/Evaluation + Level 0~5 학습 문서 + 기존 `b1-1-70-review-pack.md`.

> Review 완료는 Runtime PASS가 아니다. 실제 시스템 실행과 Evidence가 별도로 있어야 `RUNTIME VERIFIED`, Evaluation/제출 기준까지 충족해야 `MISSION PASS`다.

## 시각 학습 상태

Visual Learning은 **DEFERRED**다. 현재 Review는 텍스트·구두·실습·Evidence 기준으로 진행한다.

# B1-1 — 보안 셸 (Secure Shell, SSH)

## 한 줄 설명
네트워크를 통해 다른 Linux 서버에 암호화하여 원격 접속하는 프로토콜이다.

## B1-1에서의 위치
SSH 접속 포트를 TCP `20022`로 구성하고 Root 원격 로그인을 차단한다.

## 핵심 관계
`Client → TCP → Firewall → 20022 → sshd → 로그인`

## 초미니 확인
SSH와 `sshd`가 같은 것이 아닌 이유를 설명한다.

# B1-1 — 보안 셸 (Secure Shell, SSH)

## 학습 만화

![B1-1 SSH 한 장 학습 만화](./assets/b1-1-20-090-ssh-comic.webp)

> 이 만화는 입문자의 개념 이해를 돕는 시각 학습 자료다. B1-1의 고정값은 원본 Mission/Evaluation을 우선하며, 이 미션에서 SSH 접속 포트는 TCP `20022`, Root 원격 로그인은 차단한다.

## 한 줄 설명
네트워크를 통해 다른 Linux 서버에 암호화하여 원격 접속하는 프로토콜이다.

## B1-1에서의 위치
SSH 접속 포트를 TCP `20022`로 구성하고 Root 원격 로그인을 차단한다.

## 핵심 관계
`Client → TCP → Firewall → 20022 → sshd → 로그인`

## 초미니 확인
SSH와 `sshd`가 같은 것이 아닌 이유를 설명한다.

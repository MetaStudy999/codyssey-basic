# B1-1 — 프로세스 식별자 (Process Identifier, PID)

## 한 줄 설명
실행 중인 각각의 프로세스를 구분하기 위해 운영체제가 부여하는 숫자다.

## B1-1에서의 위치
`monitor.log`의 각 상태 기록에 Agent PID를 포함한다.

## 핵심 관계
`Process 1개 ↔ 특정 시점의 PID`; 프로세스가 다시 시작되면 PID가 달라질 수 있다.

## 초미니 확인
왜 프로그램 이름과 PID를 함께 보면 상태 확인에 도움이 되는지 설명한다.

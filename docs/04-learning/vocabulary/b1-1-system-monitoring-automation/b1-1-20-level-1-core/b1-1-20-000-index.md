# B1-1 Level 1 — Top Core Term Index

**목적:** B1-1 Top Core 28개를 `한 파일 = 한 용어` 단위로 학습한다.  
**Source of Truth:** B1-1 원본 Mission/Evaluation + 상위 [B1-1 Index](../b1-1-00-index.md).  
**학습 Gate:** V2 의미 → V3 관계.

> 이 디렉터리는 기존 Level 1 핵심 학습 내용을 개별 용어 단위로 분해한 학습용 구조다. 설명·비유·퀴즈·만화는 이해를 돕는 보조 자료이며 새로운 미션 요구사항이 아니다.

## 시각 학습(Visual Learning) Pilot

개별 용어에 `표지/한 줄 설명/미션 위치/핵심 관계/초미니 확인/Gate`를 한 장에 압축한 학습 만화를 단계적으로 연결한다.

- **게시 완료:** [Linux](./b1-1-20-010-linux.md) — 한 장 학습 만화 포함
- 이미지 파일은 `assets/`에 두고 해당 용어 문서가 상대경로로 참조한다.
- 이미지 안의 수치·계정·그룹·포트·경로가 원본 Mission/Evaluation과 충돌하면 `main`에 게시하지 않는다.
- 정확성 검증을 통과한 용어부터 순차적으로 확대하고, Level 마지막에는 전체 관계를 한 장으로 정리한 요약 만화를 둔다.

## Dependency Map

```text
Linux
  ↓
User Account → Root → sudo → User/Group → Permission → ACL → PoLP
  ↓
SSH → sshd → TCP → Port → Firewall → UFW/firewalld
  ↓
Process → PID → LISTEN
  ↓
Environment Variable → Shell Script → Bash
  ↓
System Monitoring → Health Check → CPU/MEM/DISK → Log
  ↓
cron → crontab → Log Rotation → Exit Status
```

# B1-1 — 로그 (Log)

## 한 줄 설명
시스템이나 프로그램의 상태와 사건을 시간 순서로 남긴 기록이다.

## B1-1에서의 위치
`/var/log/agent-app/monitor.log`에 timestamp, PID, CPU, MEM, DISK_USED를 누적 기록한다.

## 핵심 관계
`Monitoring 결과 → Log append → cron으로 시간축 누적 → Rotation으로 크기 관리`.

## 초미니 확인
모니터링 로그에 `>`보다 `>>`가 필요한 이유를 설명한다.

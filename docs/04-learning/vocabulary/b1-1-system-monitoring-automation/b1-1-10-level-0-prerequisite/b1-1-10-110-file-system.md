# B1-1 — 파일 시스템 (File System)

## 한 줄 설명
파일과 디렉터리를 저장하고 경로·권한·메타데이터로 관리하는 체계다.

## B1-1에서의 위치
이 용어는 B1-1의 명령·권한·프로세스·네트워크·로그 설명을 읽기 위한 선수 개념이다. Level 0에서는 깊은 원리보다 **보고 알아보는 것(V1)**을 목표로 한다.

## 핵심 관계
File/Directory와 Permission을 운영체제 수준에서 연결한다.

## 초미니 확인

# 표준 출력 (Standard Output, stdout)

**한 줄:** 정상적인 프로그램 결과를 기본적으로 내보내는 출력 스트림이다.

**B2-1 위치:** 목록·요약·성공 메시지는 일반적으로 표준 출력으로 보인다.

**핵심 관계:** program → stdout → terminal.

**초미니 확인:** 정상 거래 목록이 표시되는 기본 통로는?

**V1 Gate:** stdout을 정상 출력 통로로 설명한다.

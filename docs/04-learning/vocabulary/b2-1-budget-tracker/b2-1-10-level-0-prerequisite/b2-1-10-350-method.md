# 메서드 (Method)

**한 줄:** 클래스나 객체에 소속되어 동작하는 함수다.

**B2-1 위치:** 저장소 객체가 거래를 추가·검색하는 동작을 메서드로 제공할 수 있다.

**핵심 관계:** class/object → method → behavior.

**초미니 확인:** 객체에 속한 함수를 무엇이라 하는가?

**V1 Gate:** method가 클래스에 소속된 함수임을 말한다.

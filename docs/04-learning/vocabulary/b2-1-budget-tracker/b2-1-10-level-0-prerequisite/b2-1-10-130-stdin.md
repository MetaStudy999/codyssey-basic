# 표준 입력 (Standard Input, stdin)

**한 줄:** 프로그램이 기본적으로 문자 입력을 받는 입력 스트림이다.

**B2-1 위치:** 대화형 `input()` 입력은 터미널 표준 입력과 연결된다.

**핵심 관계:** keyboard/pipe → stdin → program.

**초미니 확인:** 사용자가 터미널에 입력한 문자가 들어오는 기본 통로는?

**V1 Gate:** stdin을 기본 입력 통로로 말한다.

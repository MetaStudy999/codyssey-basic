# B2-1 Review — Integrated Retrieval Index

**목적:** Level 0~5에서 배운 B2-1 지식을 새로 읽는 대신, 스스로 회상·복원·진단·설명하여 실제 학습 준비도를 점검한다.  
**Gate:** INTEGRATED-RETRIEVAL — V1~V5, Troubleshooting, Evidence를 한 흐름으로 연결한다.  
**Visual Learning:** DEFERRED

## Source / Evidence 경계

- Mission 요구는 B2-1 원본 Source를 따른다.
- 평가 범위는 현재 `b2-1-evaluation.md`의 4개 영역을 사용한다: 기능·예외 처리, 모듈·클래스 설계, 제너레이터·데코레이터·타입 힌트, 저장 포맷·확장성.
- 현재 구현의 JSONL, `os.replace()`, rollback import, `@cli_guard` 등은 구현 예시이며 Mission의 유일한 정답이 아니다.
- 기존 18/18 테스트 결과는 구현 저장소의 Evidence다. 학습자의 개인 재실행·평가 PASS를 대신하지 않는다.

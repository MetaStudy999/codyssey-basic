# 파일 기반 저장 (File-Based Storage)

**쉬운 뜻:** 데이터베이스 대신 일반 파일을 읽고 쓰며 데이터를 보존하는 방식이다.

**B2-1 위치:** Mission은 JSONL 또는 CSV 파일 기반 저장을 요구한다.

**핵심 관계:** data model ↔ serializer/parser ↔ files.

**미니 확인:** B2-1 필수 구현에 데이터베이스가 필요한가?

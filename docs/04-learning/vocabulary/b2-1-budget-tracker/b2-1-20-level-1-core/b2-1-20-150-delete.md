# 삭제 (Delete)

**쉬운 뜻:** 저장된 데이터에서 특정 항목을 제거하는 동작이다.

**B2-1 위치:** `delete --id`로 거래를 제거하며 없는 id도 오류로 처리한다.

**핵심 관계:** id lookup → exclude record → safe rewrite.

**미니 확인:** 없는 id를 삭제하려 하면 성공으로 처리해야 하는가?

**Gate:** delete가 단순 줄 삭제가 아니라 저장 안정성과 연결됨을 말한다.

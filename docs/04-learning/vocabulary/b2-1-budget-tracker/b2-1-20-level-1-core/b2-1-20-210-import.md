# 가져오기 (Import)

**쉬운 뜻:** 외부 CSV 데이터를 읽어 애플리케이션의 거래 데이터로 등록하는 기능이다.

**B2-1 위치:** `import --from <csv>`로 고정 스키마를 검증해 반영한다.

**핵심 관계:** CSV rows → validate all → persist transactions.

**미니 확인:** 현재 구현은 깨진 행이 하나 있으면 부분 반영하는가 전체 취소하는가?

**Gate:** import를 schema validation과 data integrity에 연결한다.

# yield 문 (yield Statement)

**쉬운 뜻:** 함수 실행을 끝내지 않고 값을 하나 내보낸 뒤 상태를 기억하고 다음 호출 때 이어가게 하는 문법이다.

**B2-1 위치:** 파일 레코드를 한 건씩 제공하는 generator 함수의 핵심이다.

**핵심 관계:** yield → pause/resume → lazy sequence.

**미니 확인:** `return`처럼 함수가 완전히 끝나는 것과 `yield`의 차이는?

**Gate:** yield가 generator를 만드는 핵심 문법임을 설명한다.

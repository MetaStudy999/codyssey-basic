# 수입 (Income)

**쉬운 뜻:** 돈이 들어오는 거래 유형이다.

**B2-1 위치:** Transaction의 `type=income`으로 표현한다.

**핵심 관계:** income sum - expense sum = balance.

**미니 확인:** 월급은 보통 income인가 expense인가?

**Gate:** income이 summary의 총수입과 잔액 계산에 연결됨을 말한다.

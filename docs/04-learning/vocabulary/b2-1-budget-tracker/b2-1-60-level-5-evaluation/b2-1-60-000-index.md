# B2-1 Level 5 — Evaluation Unit Index

**목적:** B2-1 공식 평가 문항을 `WHAT → WHY → HOW → PROOF → LIMIT / ENVIRONMENT → FOLLOW-UP` 구조로 자기 설명한다.  
**Gate:** V5 — 기능·설계·원리·증거·한계를 연결해 1분 또는 3~5분 답변으로 설명한다.  
**Visual Learning:** DEFERRED

## Source / Evidence 경계

- 평가 질문은 현재 구현 저장소의 `b2-1-evaluation.md`를 기준으로 한다.
- 구체 구현 예시는 `budget_app/`와 `tests/test_budget_app.py`, `evidence/`를 연결한다.
- 기존 **18/18 테스트 통과 Evidence**는 구현 저장소의 기록이다. 학습자 본인의 재실행·평가 PASS를 대신하지 않는다.
- JSONL, option-based update, `os.replace()`, rollback import, `@cli_guard`는 현재 구현 선택이며 Mission의 유일한 정답으로 승격하지 않는다.

## 평가 답변 프레임

```text

→ 무엇을 구현/관찰했는가?
WHY
→ 왜 그렇게 설계했는가?
HOW
→ 어디에서 어떻게 동작하는가?
PROOF
→ 어떤 테스트/출력/파일이 증명하는가?
LIMIT / ENVIRONMENT
→ 현재 설계의 한계와 적용 범위는 무엇인가?
FOLLOW-UP
→ 대안·확장·꼬리질문에 어떻게 답할 것인가?
```

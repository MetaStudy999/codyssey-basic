# B5-1 미션 용어 지도

**미션:** 정보를 깔끔하게 정리하는 디지털 서랍장 만들기  
**분야:** 데이터베이스와 백엔드 (Database & Backend)  
**학습시간:** 40시간  
**표기 원칙:** 한글 용어 (English Term, 약어)  
**상태:** 1차 용어 목록 작성 완료 — 설명은 후속 학습 단계에서 추가

> 기준: B5-1 원본 Mission PDF의 미션 소개, 최종 결과물, 과제 목표, 기능 요구 사항, 보너스 과제, 개발 환경, 제약 사항, 결과 예시를 우선 반영한다. 원본에서 직접 요구하거나 설계·SQL 작성·검증·평가에 필요한 용어를 중심으로 구성하며, 현재 단계에서는 용어 설명을 넣지 않는다.

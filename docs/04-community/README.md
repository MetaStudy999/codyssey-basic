# 04. Community

마리너·동료와 함께 문제를 해결하며 협업 역량을 키우는 영역이다.

## 기본 활동

- Study
- Code Review Dojo
- Debugging Clinic
- Architecture Cafe
- Failure Lab
- Pair Programming / Pair Debugging
- Mentoring / Explain & Teach

## 운영 원칙

CORE부터 활용할 수 있으며 실제 활동이 `ACTIVE`가 되어 독립 결과물이 생길 때 세부 폴더를 Just-in-Time으로 생성한다.

Activity 상태는 `config/activities.yaml`을 따른다.

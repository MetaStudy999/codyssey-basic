# 02. Domains

기초과정은 필수/선택 여부가 아니라 **7개 기술 대분류**로 관리한다.

1. Linux와 OS
2. Python과 Git 심화
3. 자료구조와 알고리즘
4. 웹 핵심과 프론트엔드
5. 데이터베이스와 백엔드
6. 클라우드와 AI API
7. Term Project

각 Domain은 다음 공통 구조를 따른다: 영역 소개 → 학습 목표 → 선행 지식 → 포함 Mission → 핵심 개념/기술 → Mission 간 연결 → 이전/다음 영역 연결 → 결과물 → 완료 기준 → 참고자료 → 전문가 성장 → 고도화.

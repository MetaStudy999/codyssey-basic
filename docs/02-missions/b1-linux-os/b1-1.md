# B1-1 — System Monitoring Automation

## Mission Identity

- 제목: 컴퓨터가 알아서 자기 상태를 점검하게 만들기
- 영역: Linux & OS
- 공식 구분: 필수
- Repository: https://github.com/MetaStudy999/codyssey-basic-b1-1-system-monitor
- Growth Stage: `CORE`

실제 수행 상태와 G1~G8은 `config/missions.yaml`을 Source of Truth로 사용한다.

## Core Goal

안전한 Linux 서버 실행 환경을 구성하고 시스템 상태 수집을 자동화한다.

## Core Terms

- User / Group
- Permission / ACL
- SSH
- Firewall / UFW
- Environment Variable
- Shell Script
- Logging
- cron
- Process / System Resource

## Core Flow

```text
접속/계정 정책
   ↓
권한/ACL
   ↓
Firewall
   ↓
Agent 실행 환경
   ↓
monitor.sh
   ↓
Log
   ↓
cron 자동 실행
   ↓
Runtime Verification
   ↓
Evidence
```

## Core Requirement Summary

기존 Control Tower가 관리하는 B1-1 요구 요약:

- SSH 포트 변경
- root 원격 로그인 제한
- 방화벽 규칙
- 사용자/그룹/ACL 구성
- Agent 실행 환경
- `monitor.sh`
- 로그 기록
- cron 자동 실행
- 실제 환경에서의 검증과 Evidence

공식 세부 요구는 Mission Source와 개별 Repository의 Work Packet을 기준으로 다시 확인한다.

## Completion Gate

`G1 SOURCE → G2 BUILD → G3 TEST → G4 REVIEW → G5 RUNTIME → G6 EVIDENCE → G7 LEARN → G8 MERGE`

## Learning

B1-1의 기존 학습 자산은 `docs/04-learning/vocabulary/b1-1-system-monitoring-automation/`에 연결되어 있다.

CORE에서는 최소한 다음이 가능해야 한다.

```text
용어 설명
→ 설정 이유 설명
→ 직접 실행
→ 정상/오류 상태 구분
→ 문제 발생 시 확인 순서 설명
→ Evidence로 평가 항목 설명
```

# B7-2 — Advanced AI Chatbot

## Project

B7-1을 확장해 사용자 소유 Chat Session, 게시판 CRUD, REST API, Cloud 배포, ERD/API Spec/Architecture 문서와 팀 Branch Strategy까지 갖춘 고도화 Full-stack AI Service를 만든다.

## CORE

- 인증된 사용자별 Chat Session 소유권
- 대화 기록 관리
- Board CRUD
- REST API
- 관계형 Database 모델
- Cloud 배포
- ERD / API Specification / Architecture 문서
- 팀 Branch/PR/Review 전략
- 핵심 정상/실패 사용자 흐름 검증

## EXPLORE

실사용자 피드백, AI Evaluation, RAG/Agent, Open Source, Competition, Research Question, Startup Problem Fit을 탐색한다.

## ADVANCED

RAG, Agent Workflow, Evaluation Pipeline, Security, Observability, Load/Performance Test, CI/CD, Cost Optimization을 선택적으로 깊게 고도화한다.

## PRO 연결

Production Service, 외부 사용자, 기업 PoC, 연구 프로젝트, 학회/논문, Open Source, Startup MVP로 이어지는 대표 통합 프로젝트로 발전시킨다.

## EXPERT 연결

모델·아키텍처·비용·보안·운영·사용자 가치 사이의 Trade-off를 스스로 판단하고 기술 방향을 설명할 수 있는 수준으로 확장한다.

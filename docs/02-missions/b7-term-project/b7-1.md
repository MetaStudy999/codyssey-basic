# B7-1 — Web AI Chatbot

## Project

FastAPI 기반 웹 서비스에 로그인, AI API, 대화 기록 Database, 배포, 팀 협업과 문서화를 통합하여 실제 사용 가능한 AI Chatbot Service를 만든다.

## CORE

- 사용자 Login
- AI API 연동
- 대화 Session/Message 저장
- Database 연동
- Web UI와 Backend 통합
- Cloud 배포
- 팀 Git/PR/Review 협업
- Architecture/사용법/운영 문서화
- 실제 사용자 흐름 검증

## EXPLORE

다른 Model/API, AI UX, Prompt 전략, 간단한 사용자 테스트, Hackathon/공모전 출품 가능성을 탐색한다.

## ADVANCED

Evaluation, Security, Observability, Streaming, Context Management, RAG, CI/CD, Performance를 선택하여 고도화한다.

## PRO 연결

실사용자 서비스, 기업 PoC, 연구 실험, Hackathon/Competition, Open Source 또는 Startup MVP로 재사용하는 핵심 Project Lineage의 시작점으로 삼는다.

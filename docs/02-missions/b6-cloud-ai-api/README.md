# B6 — Cloud & AI API

## 목표

로컬에서 만든 서비스를 외부에서 접근 가능한 Cloud 환경에 배포하고, AI API를 안전하게 연결해 운영·자동화의 기본을 익힌다.

## 포함 Mission

- [B6-1 Cloud Deployment](./b6-1.md)
- [B6-2 AI Git Assistant](./b6-2.md)

## CORE

VPC/Subnet/Route/Internet Gateway/Compute/Security Group/IAM과 API Key·Prompt·CLI·Error Handling을 실제 환경에서 검증한다.

## EXPLORE

Domain/HTTPS, Docker, 다른 Cloud, 다른 AI API, 간단한 Monitoring, 비용 구조를 짧게 비교한다.

## ADVANCED

CI/CD, IaC, Observability, Security Hardening, Cost/Performance Optimization, Prompt Evaluation, Guardrail을 선택적으로 심화한다.

## PRO

실서비스에서 Availability, Security, Cost, Deployment Risk, AI API 품질과 장애를 책임지는 Cloud/AI Engineering으로 확장한다.

## 연결

B6의 Cloud 운영과 AI API 경험은 B7 Full-stack AI Service를 실제 외부 사용자에게 제공하기 위한 기반이 된다.

# B6-2 — AI Git Assistant

## Mission

Python CLI가 Git 상태와 Diff를 수집하고 AI API를 호출해 Commit Message와 Pull Request 초안을 생성하도록 구현한다.

## CORE

- Git Status / Diff 수집
- AI API 호출
- Prompt 설계
- Commit Message 생성
- PR Draft 생성
- API Key를 환경변수로 관리
- CLI Option과 Error Handling
- README와 실행 예시 제공

## EXPLORE

다른 LLM/API, Prompt Pattern, Structured Output, Token/Cost 비교, 간단한 평가 기준을 체험한다.

## ADVANCED

Prompt Evaluation, Retry/Timeout, Rate Limit, Model Routing, Guardrail, Secret Management, Observability를 심화한다.

## PRO 연결

개발팀 Workflow에 실제 적용하여 품질·비용·보안·신뢰성을 측정하고 AI-assisted Engineering Tool로 운영하는 경험으로 확장한다.

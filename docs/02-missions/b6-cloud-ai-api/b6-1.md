# B6-1 — Cloud Deployment

## Mission

VPC, Subnet, Route Table, Internet Gateway, EC2, Security Group, IAM을 구성하여 외부에서 접근 가능한 Cloud 서비스를 배포하고 운영 증거를 확보한다.

## CORE

- VPC / Subnet / Route Table / Internet Gateway
- Compute Instance 생성과 접근
- Security Group 최소 허용
- IAM Least Privilege
- 외부 접속 확인
- 장애 원인과 해결 기록
- 사용 후 자원 정리

## EXPLORE

Domain, HTTPS, Nginx, Docker, CloudWatch/Monitoring, 다른 Cloud 서비스를 짧게 비교한다.

## ADVANCED

CI/CD, IaC, Load Balancer, Auto Scaling, Backup, Observability, Security Hardening, Cost Optimization을 심화한다.

## PRO 연결

실서비스에서 Availability, Security, Incident, Cost, Capacity, Change Risk를 책임지는 Cloud/SRE Engineering으로 확장한다.

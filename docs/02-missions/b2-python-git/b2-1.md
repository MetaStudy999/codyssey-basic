# B2-1 — Budget Tracker

## Mission

Python 콘솔 환경에서 수입·지출 데이터를 기록하고 조회·검색·요약·가져오기·내보내기를 수행하는 파일 기반 예산 관리 프로그램을 만든다.

## CORE

- CRUD와 검색/요약 흐름 구현
- JSONL/CSV 기반 파일 영속성
- Generator, Decorator, Type Hint 활용
- 기능을 역할별 모듈로 분리
- 입력 오류와 파일 처리 예외를 다루고 실제 실행으로 검증

## Evidence

Source → Requirement → Implementation → Test → Runtime → Evidence → PASS의 연결을 유지한다.

## EXPLORE

CLI UX, 다른 직렬화 형식, 데이터 검증, 테스트 프레임워크, 패키징을 짧게 비교한다.

## ADVANCED

Atomic Rewrite, Backup, Recurring Transactions, stronger validation, 자동화 테스트와 품질 측정을 심화한다.

## PRO 연결

실제 개인/팀 도구로 사용하면서 데이터 손실 방지, 유지보수성, 변경 호환성을 책임지는 작은 Production Tool로 발전시킬 수 있다.

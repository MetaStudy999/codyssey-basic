# B2 — Python & Git

## 목표

Python으로 유지보수 가능한 프로그램을 만들고 Git/GitHub 협업 흐름을 실제 팀 작업으로 익힌다.

## 포함 Mission

- [B2-1 Budget Tracker](./b2-1.md)
- [B2-2 Git Team Collaboration](./b2-2.md)

## CORE

Python 프로그램 구조화, 파일 기반 데이터 처리, Git 기본 조작, Issue → Branch → Commit → PR → Review → Merge 흐름을 직접 수행한다.

## EXPLORE

오픈소스 Repository 읽기, Pair Programming, Code Review Dojo, 작은 팀 프로젝트, Git 세미나를 통해 협업 방식의 폭을 넓힌다.

## ADVANCED

테스트 자동화, 패키징, CI, 고급 Git 복구 전략, Branch/Release 전략, 협업 규칙과 품질 Gate를 설계한다.

## PRO

실제 팀/오픈소스/기업 프로젝트에서 변경 이력과 리뷰 품질을 책임지고 충돌·회귀·배포 위험을 관리한다.

## 연결

B2-2의 GitHub Flow와 Review 습관은 이후 B3~B7 전체 Mission 및 외부 프로젝트의 기본 협업 운영체계로 재사용한다.

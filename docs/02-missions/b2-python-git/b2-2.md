# B2-2 — Git Team Collaboration

## Mission

3~5명이 하나의 팀 Repository에서 GitHub Flow를 사용해 Issue, Branch, Pull Request, Review, Merge, Conflict Resolution을 실제 협업 기록으로 남긴다.

## CORE

- 팀 Repository와 협업 권한 구성
- `main` Branch Protection 적용
- Issue → Branch → Commit → PR → Review → Merge 흐름 수행
- 팀원별 PR과 Review Evidence 확보
- PR과 Issue 연결
- 충돌 해결 기록 확보
- `amend / reset / revert / stash` Troubleshooting 시나리오 수행
- 협업 결과를 `SUBMISSION.md` 등 제출 Evidence와 연결

## EXPLORE

Pair Programming, Code Review Dojo, 다른 팀의 PR 읽기, 오픈소스 Issue/PR 탐색을 통해 협업 방식의 폭을 넓힌다.

## ADVANCED

PR Template, CODEOWNERS, CI Gate, Release/Branch Strategy, Review Checklist, Conflict Prevention Rule을 설계한다.

## PRO 연결

실제 팀 또는 오픈소스 프로젝트에서 변경 위험, 리뷰 품질, 추적성, 협업 규칙을 책임지는 Engineering Workflow로 발전시킨다.

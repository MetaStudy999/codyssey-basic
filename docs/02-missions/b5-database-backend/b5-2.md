# B5-2 — FastAPI CRUD Service

## Mission

FastAPI, SQLAlchemy, SQLite, Jinja2를 이용해 하나의 핵심 모델에 대한 CRUD 웹 서비스를 구현하고 Router → Service → Repository 역할을 분리한다.

## CORE

- 목록/상세/등록/수정/삭제 CRUD
- FastAPI Router와 Request 흐름
- Service/Repository 역할 분리
- SQLAlchemy ORM과 SQLite
- Jinja2 Server-side Rendering
- Form Validation과 오류 처리
- PRG(Post/Redirect/Get) 흐름
- 실제 실행과 핵심 경로 검증

## EXPLORE

PostgreSQL, REST API 전용 구조, Migration, API Client, Flask/Django 비교를 짧게 경험한다.

## ADVANCED

Automated Test, Migration, PostgreSQL, Async, Architecture, Security, Performance, Cache를 선택적으로 심화한다.

## PRO 연결

실서비스에서 API/DB 변경, 장애, 성능, 관측성, 배포 안정성을 책임지는 Backend Engineering으로 발전시킨다.

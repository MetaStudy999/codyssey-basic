# B5-3 — FastAPI Auth & Relations

## Mission

FastAPI 서비스에 로그인/로그아웃, 사용자별 권한, 3개 이상 모델 관계, 상태 변경 비즈니스 로직을 추가하여 실제 서비스에 가까운 인증·관계형 Backend를 구현한다.

## CORE

- Login / Logout
- 인증된 사용자 Context와 Authorization
- 3개 이상 Model
- 1:N / N:1 Relationship
- ORM Relationship 사용
- `Depends` 기반 인증 의존성
- 사용자 소유권과 권한 검증
- 상태 변경 Business Logic
- 핵심 정상/실패 경로 검증

## EXPLORE

Session/JWT 차이, Password Hashing, Role/Permission 모델, OAuth 개념, API Security 기본을 비교한다.

## ADVANCED

Token Lifecycle, CSRF/CORS, RBAC/ABAC, Audit Log, Integration Test, Security Testing, Transaction Boundary를 심화한다.

## PRO 연결

실서비스에서 Identity, Authorization, 개인정보·보안 위험과 Business Rule 변경을 책임지는 Backend/Security Engineering으로 확장한다.

# B5 — Database & Back-end

## 목표

관계형 데이터 모델링에서 시작해 FastAPI CRUD, 인증·권한·관계·비즈니스 로직까지 확장하여 서비스의 데이터와 서버 계층을 이해한다.

## 포함 Mission

- [B5-1 SQL Database Design](./b5-1.md)
- [B5-2 FastAPI CRUD](./b5-2.md)
- [B5-3 FastAPI Auth & Relations](./b5-3.md)

## CORE

ERD/관계/제약조건, SQL Query, ORM, CRUD, Router/Service/Repository 역할 분리, 인증·인가와 모델 관계를 실제 서비스 흐름으로 구현한다.

## EXPLORE

PostgreSQL, Migration, API Client, 다른 Backend Framework, API 문서화와 작은 성능 실험을 체험한다.

## ADVANCED

Transaction, Index, Query Plan, Async, Cache, Testing, Security, Architecture, Performance를 선택적으로 깊게 다룬다.

## PRO

실제 서비스에서 데이터 일관성, 권한, 성능, 장애, 스키마 변경과 운영 위험을 책임지는 Backend Engineering으로 확장한다.

## 연결

B5의 데이터·API·인증 기반은 B6 Cloud 배포와 B7 Full-stack AI Service의 핵심 서비스 계층이 된다.

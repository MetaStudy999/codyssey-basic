# B5-1 — SQL Database Design

## Mission

관계형 데이터베이스를 설계하고 SQL만으로 테이블, 제약조건, 샘플 데이터, 조회/집계/조인 Query를 작성해 데이터 모델을 검증한다.

## CORE

- 4개 이상 Table 설계
- PK / FK / UNIQUE / NOT NULL 등 Constraint
- 1:N 관계 2개 이상
- Table별 충분한 Sample Data
- 조회·조건·정렬·집계·JOIN 등 SQL Query 작성
- ERD와 SQL 정의의 일관성 검증

## EXPLORE

PostgreSQL/SQLite 차이, Index, Normalization, Query Plan, DB Client 도구를 짧게 비교한다.

## ADVANCED

Normalization/Denormalization Trade-off, Index Design, Transaction, Isolation, Query Optimization, Migration을 심화한다.

## PRO 연결

실서비스에서 스키마 변경, 데이터 무결성, Query 성능, 운영 안전성을 고려해 데이터 모델을 설계하고 판단하는 역량으로 확장한다.

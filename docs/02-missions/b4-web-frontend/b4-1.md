# B4-1 — Responsive Portfolio

## Mission

HTML, CSS, JavaScript로 반응형 포트폴리오를 만들고 GitHub API 연동, 상태 처리, Dark Mode, GitHub Pages 배포까지 검증한다.

## CORE

- Semantic HTML
- Responsive CSS
- DOM/Event 처리
- GitHub API 데이터 표시
- Loading / Error / Empty 상태
- Dark Mode와 `localStorage`
- GitHub Pages 배포

## EXPLORE

접근성 점검, 디자인 시스템, Lighthouse, 다른 공개 API, 사용자 피드백을 짧게 경험한다.

## ADVANCED

접근성, 성능 최적화, CSS Architecture, Web Components/Framework 비교, Front-end Testing을 심화한다.

## PRO 연결

실제 포트폴리오·서비스에서 사용자 행동과 성능 지표를 측정하고 개선하며 안정적인 공개 웹 자산을 운영하는 경험으로 연결한다.

# B4 — Web & Front-end

## 목표

HTML/CSS/JavaScript의 웹 기본 원리를 직접 다룬 뒤 React SPA로 확장하여 사용자 인터페이스의 구조와 상태 흐름을 이해한다.

## 포함 Mission

- [B4-1 Portfolio](./b4-1.md)
- [B4-2 React SPA](./b4-2.md)

## CORE

Semantic HTML, Responsive CSS, DOM/Event, API Fetch, UI State와 React Component/Route/Form/CRUD 흐름을 구현하고 배포 환경에서 검증한다.

## EXPLORE

접근성, UI/UX, 디자인 시스템, 다른 Front-end Framework, 사용자 테스트를 비교·체험한다.

## ADVANCED

Component Architecture, State Management, Testing, Performance, Accessibility, Design System, Front-end Observability를 심화한다.

## PRO

실사용자가 있는 웹 서비스에서 성능·접근성·사용성·변경 안정성을 측정하고 개선하는 Front-end Engineering으로 확장한다.

## 연결

B4의 사용자 인터페이스는 B5 Backend API와 결합되고 B7 Full-stack AI Service의 사용자 경험 계층이 된다.

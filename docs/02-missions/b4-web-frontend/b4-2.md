# B4-2 — React SPA

## Mission

React 기반 Single Page Application에서 여러 Route, CRUD, Controlled Form, 상태 처리, 재사용 Component와 외부 데이터 저장소 연동을 구현하고 배포 환경에서 검증한다.

## CORE

- 5개 이상 Route와 Not Found 처리
- 목록/상세/등록/수정/삭제 CRUD
- Supabase 또는 Firebase 등 외부 데이터 저장소 연동
- Controlled Form과 필수값 검증
- Loading / Error / Empty 상태 일관성
- 재사용 Component와 Custom Hook/Lib 분리
- 배포 URL에서 전체 기능 검증

## EXPLORE

다른 상태관리 방식, UI Library, API 구조, SSR/SPA 차이, 사용자 테스트를 짧게 비교한다.

## ADVANCED

Component Architecture, Query/Cache 전략, Testing, Accessibility, Performance, Error Boundary, Observability를 심화한다.

## PRO 연결

실사용자가 있는 Front-end에서 변경 안정성, 성능, 데이터 일관성, 사용자 경험을 측정하고 운영하는 능력으로 확장한다.

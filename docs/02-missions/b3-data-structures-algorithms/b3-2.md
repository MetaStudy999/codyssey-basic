# B3-2 — Mini Git

## Mission

Commit Graph, Branch, Search, Sort, Ancestor/Shortest Path 로직을 직접 구현하여 버전 관리 시스템의 핵심 원리를 이해하는 작은 Git을 만든다.

## CORE

- Commit을 DAG(Directed Acyclic Graph)로 관리
- Branch/HEAD 개념 구현
- 검색을 위한 Inverted Index
- 정렬 알고리즘 직접 구현
- Ancestor/Shortest Path 탐색
- CLI/REPL에서 Commit/Branch/Search 흐름 검증

## EXPLORE

실제 Git object/commit graph를 읽어 보고 `log`, `branch`, `merge-base` 등 실제 명령과 구현 개념을 비교한다.

## ADVANCED

그래프 알고리즘 복잡도, Merge 개념, Object Storage, Pack/Compression, 대규모 Repository 성능 문제를 선택적으로 심화한다.

## PRO 연결

대형 Repository, CI/CD, 협업 시스템에서 History/Branch/Dependency 구조를 해석하고 버전 관리 전략을 판단하는 능력으로 연결한다.

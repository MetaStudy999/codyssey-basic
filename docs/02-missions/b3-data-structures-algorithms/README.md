# B3 — Data Structures & Algorithms

## 목표

라이브러리를 사용하는 수준을 넘어 핵심 자료구조와 탐색·정렬·그래프 원리를 직접 구현하며 내부 동작을 이해한다.

## 포함 Mission

- [B3-1 Mini Redis](./b3-1.md)
- [B3-2 Mini Git](./b3-2.md)

## CORE

Hash Map, Linked List, Heap, LRU, TTL, DAG, Search, Sort, Graph Traversal 등 미션이 요구하는 구조를 직접 구현하고 CLI에서 검증한다.

## EXPLORE

실제 Redis/Git 동작 비교, 알고리즘 시각화, Whiteboard Study, Benchmark 실험으로 구현과 실제 시스템의 차이를 탐색한다.

## ADVANCED

복잡도 분석, Benchmark, Memory/Latency Trade-off, 동시성·영속성·확장성 문제를 선택적으로 심화한다.

## PRO

실서비스에서 캐시·인덱스·버전 그래프·검색 구조를 선택하고 성능과 운영 복잡도를 증거 기반으로 판단한다.

## 연결

B3에서 익힌 내부 원리와 Trade-off 사고는 B5 데이터 처리, B6 운영, B7 AI 서비스 성능·상태 관리의 기반이 된다.

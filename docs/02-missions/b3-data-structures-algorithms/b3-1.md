# B3-1 — Mini Redis

## Mission

Hash Map, Doubly Linked List, Min-Heap 등을 조합해 작은 In-memory Data Store를 구현하고 LRU, TTL, Memory Limit 동작을 CLI에서 검증한다.

## CORE

- Chaining 기반 Hash Map
- Doubly Linked List 기반 LRU
- Min-Heap 기반 TTL 만료 관리
- Memory Limit과 Eviction 정책
- CLI 명령 처리와 상태 검증

## EXPLORE

실제 Redis 명령과 비교하고 캐시 사용 사례, TTL 전략, Cache Hit/Miss 개념을 작은 실험으로 확인한다.

## ADVANCED

자료구조별 시간·공간 복잡도, Benchmark, Eviction Policy 비교, 동시성·Persistence 가능성을 심화한다.

## PRO 연결

실서비스 Cache 설계에서 Latency, Memory, Consistency, Operational Cost를 비교하여 Redis 또는 다른 대안을 선택하는 문제로 확장한다.

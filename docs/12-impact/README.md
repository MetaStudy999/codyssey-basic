# 12. Impact

Growth OS의 최종 목적은 칭호가 아니라 **실제 변화와 기여**다.

## Impact 영역

- Engineering: 서비스/시스템의 품질·성능·안정성 개선
- Research: 새로운 지식·실험·논문·재현 가능한 결과
- Community: 교육, 멘토링, 오픈소스, 팀 성장
- Venture: 사용자 문제 해결, 제품, 고객, 사업화

## EXPERT 이후

`Tech Lead / Principal`, `Architect / SRE`, `AI / Researcher`, `Open Source`, `Educator / Mentor`, `Founder` 등 전문 경로로 분기하고 Evidence를 통해 실제 영향을 기록한다.

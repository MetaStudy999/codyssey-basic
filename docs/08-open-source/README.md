# 08. Open Source

외부 Repository를 읽고 Issue/PR/Review를 경험하며 실제 생태계에 기여하는 성장 경로를 관리한다.

## 단계 연결

- EXPLORE: Repository 구조, Issue, Contribution Guide 읽기
- ADVANCED: Documentation/Bug Fix/Feature PR과 Review 대응
- PRO: 지속 Contribution, Release, Maintainer 책임
- EXPERT: 기술 방향 판단과 Community Leadership

Contribution은 반드시 공개 가능한 Evidence와 연결한다.

# 07. Research

Mission과 Project에서 나온 문제를 Research Question으로 발전시켜 가설·실험·분석·재현·발표·논문으로 연결한다.

## 기본 흐름

Question → Hypothesis → Protocol → Experiment → Analysis → Reproduction → Write → Review → Submit

## 단계 연결

- EXPLORE: 논문 읽기, 분야 탐색, 학회 참석
- ADVANCED: 가설, Benchmark, Experiment, Technical Report, Poster
- PRO: 공동 연구, 학회 발표, 논문 투고
- EXPERT: 새로운 연구 방향과 방법을 판단·제안

실제 연구가 `ACTIVE`가 될 때 세부 연구 폴더를 생성한다.

# 07. Portfolio

포트폴리오는 기술 이름이 아니라 **Project + Competency + Evidence**를 보여준다.

## Project
무엇을 만들었는가.

## Competency
어떤 문제를 어떤 기술과 설계로 해결할 수 있는가.

## Evidence
Source, Test, Runtime, Architecture, Troubleshooting, Demo로 어떻게 증명하는가.

## 역량 축
- Linux Operations
- Software Engineering & Git Collaboration
- Data Structures & Algorithms
- Front-end Engineering
- Database & Back-end Engineering
- Cloud & AI Integration
- Full-stack AI Engineering

GitHub Pages `site/`는 이 내용을 외부 방문자가 빠르게 이해하도록 보여주는 Presentation Layer다.

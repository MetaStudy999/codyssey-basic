# 09. Opportunities

학습한 기술을 외부 환경에서 검증하고 확장하는 기회를 관리한다.

## 카테고리
- 공모전 / 경진대회
- Hackathon
- Seminar / Conference / Meetup
- Call for Papers / Projects / Participants
- Research Opportunity
- Open Source Opportunity
- Grants / Government Support
- Startup / Accelerator / Demo Day

## 상태
`NOW`, `NEXT`, `WATCH`, `ARCHIVE`

## 등록 기준
각 기회는 공식 URL, 주최기관, 신청 마감일, 행사일, 관련 Domain/Mission, 난이도, 기대 성과, 마지막 확인일을 기록한다.

## 연결 예
- B3 → Algorithm/Coding Competition
- B4+B5 → Web/App Hackathon
- B6 → Cloud/AI Challenge
- B7 → Generative AI Hackathon, Startup/Capstone Competition

과거 행사는 단순 삭제하지 않고 영상·슬라이드·Proceedings가 있으면 Resources로 연결한다.
